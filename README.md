# GF2 VR

제작자: [@TBluebox12](https://x.com/TBluebox12)  
아카라이브 가상현실 채널: [가상현실 채널](https://arca.live/b/vrshits)

GF2 Exilium을 VR로 즐기기 위한 비공식 모드 프로젝트입니다. 지원되는 3D 장면은 입체 화면으로 보여 주고, 게임 메뉴와 일반 화면은 컨트롤러로 조작할 수 있는 패널로 표시합니다.

**현재 이 저장소에는 설정 프로그램과 인스톨러의 소스 및 안내 문서를 제공하고 있습니다. 최신 전체 설치 파일은 아직 배포하지 않습니다.** GitHub의 코드 다운로드 ZIP은 설치 파일이 아닙니다. [다운로드와 지원 안내](docs/ko/RELEASE_READINESS.md)를 먼저 확인하세요.

## 처음 사용하는 분께

1. 사용할 수 있는 설치 파일이 있는지 [다운로드 안내](docs/ko/RELEASE_READINESS.md)를 확인합니다.
2. 설치 파일을 전달받았다면 [설치 안내](docs/ko/INSTALLATION.md)에 따라 설치합니다.
3. 설정 프로그램에서 원하는 옵션을 저장한 뒤 게임과 SteamVR를 직접 실행합니다.
4. [기본 조작법](docs/ko/USAGE.md)을 확인하고, 불편한 설정은 게임을 종료한 뒤 조정합니다.

## 주요 기능

- 지원되는 3D 장면의 입체 VR 화면과 머리 움직임 반영
- 일반 게임 화면을 보여 주는 정면 패널과 필요할 때 여는 보조 패널
- 스틱 이동·회전, 컨트롤러로 화면 클릭·뒤로 가기
- 손으로 월드를 잡아 시점을 옮기는 월드 그립
- 월드 크기, 입체감, 이동 속도, 활동층 UI와 손 역할 설정
- 한국어·영어·일본어 설정 프로그램과 인스톨러
- 설정 프로필 저장·불러오기, 설치·제거·복구 안내

월드 크기 연동과 스틱 클릭으로 시점을 되돌리거나 카메라 따라가기를 바꾸는 기능은 구현했으며, 실제 VR 사용 확인은 아직 남아 있습니다. [확인된 동작과 제한 사항](docs/ko/VERIFICATION.md)에서 자세히 안내합니다.
