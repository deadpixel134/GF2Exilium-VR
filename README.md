GF2 Exilium을 VR로 즐기기 위한 비공식 모드입니다. 지원되는 3D 장면은 입체 화면으로 보여 주고, 게임 메뉴와 일반 화면은 컨트롤러로 조작할 수 있는 패널로 표시합니다.

**[정식 버전 1.0.0 다운로드](https://github.com/deadpixel134/GF2Exilium-VR/releases/tag/v1.0.0)** · [설치 안내](docs/ko/INSTALLATION.md) · [기본 조작법](docs/ko/USAGE.md)

릴리스의 **GF2VR-Native-SelfContained-1.0.0.zip**을 받으세요. 게임은 포함되어 있지 않으며, 지원 게임 빌드는 **2.0.3936**입니다. 인스톨러가 실제 게임 파일의 일치 여부를 확인합니다. [지원 환경과 확인 범위](docs/ko/VERIFICATION.md)를 함께 확인하세요.

## 처음 사용하는 분께

1. 릴리스 ZIP을 새 폴더에 전부 풉니다. GitHub의 **Source code** ZIP은 설치 파일이 아닙니다.
2. **GF2VR.Installer.exe**를 열고, **GF2 Game 폴더가 들어 있는 상위 폴더**를 선택해 설치합니다.
3. **설정 열기**에서 원하는 옵션을 저장한 뒤 SteamVR와 게임을 직접 실행합니다.
4. [기본 조작법](docs/ko/USAGE.md)을 확인하고, 불편한 설정은 게임을 종료한 뒤 조정합니다.

## 주요 기능

- 지원되는 3D 장면의 입체 VR 화면과 머리 움직임 반영
- 일반 게임 화면을 보여 주는 정면 패널과 필요할 때 여는 보조 패널
- 스틱 이동·회전, 컨트롤러로 화면 클릭·뒤로 가기
- 손으로 월드를 잡아 시점을 옮기는 월드 그립
- 월드 크기, 입체감, 이동 속도, 활동층 UI와 손 역할 설정
- 한국어·영어·일본어 설정 프로그램과 인스톨러
- 설정 프로필 저장·불러오기, 설치·업데이트·제거·이전 버전 복원

현재 구현은 사용자의 실기 테스트 완료 확인을 기준으로 정식 버전에 고정했습니다. 장치별 호환성과 모든 장면의 동작을 보증하는 것은 아닙니다. [확인된 동작과 제한 사항](docs/ko/VERIFICATION.md)에서 지원 범위를 안내합니다.
