# GF2 VR

GF2 Exilium을 위한 비공식 Windows PC용 OpenXR VR 모드 프로젝트입니다. 지원되는 실시간 3D 장면을 양안 VR로 보여 주고, 원본 게임 화면은 정면 패널이나 보조 패널로 표시해 VR 컨트롤러로 조작합니다.

이 저장소에는 현재 **설정 프로그램과 인스톨러의 소스·문서**를 게시하고 있습니다. 저장소는 비공개이며, 최신 전체 VR 모드 설치 파일이나 정식 릴리스를 배포하는 단계는 아닙니다.

## 핵심 기능

- 지원되는 3D 장면의 OpenXR 스테레오 출력과 머리 움직임 반영
- 원본 게임 화면을 사용하는 자동 정면 패널과 별도로 여닫는 보조 패널
- 스틱 이동·회전, 기본 30° 스냅 회전, 손 움직임으로 시점을 옮기는 월드 그립
- 컨트롤러 포인터를 통한 UI 클릭·뒤로 가기와 트리거 게임 모드의 WASD 입력
- 트리거를 당긴 상태에서 X/A → F, Y/B → Escape 입력
- 활동층 주 화면 UI 표시 설정과 독립된 보조 패널
- 월드 크기, 눈 간격·이동 속도 연동, 시작 시 카메라 따라가기 설정
- 한국어·영어·일본어 설정 프로그램과 인스톨러
- 설치 전 파일 검사, 작업 진행률·로그, 중단 복구, 이전 버전 복원

월드 크기 연동과 왼쪽 스틱 클릭의 원본 카메라 복귀, 오른쪽 스틱 클릭의 카메라 따라가기 전환은 구현했으며, 새 구현의 실제 HMD 확인은 추후 진행합니다. 기능 구현과 실기 검증 완료는 구분합니다.

## 설정 프로그램

설정은 **화질·입체감 / 이동·회전 / 월드 그립 / 활동층 UI / 버튼 / 월드 크기**의 6개 탭, 총 25개 항목으로 구성합니다. 각 설정 옆에서 적용 방식과 주의사항을 확인할 수 있습니다.

설정 저장, 다시 읽기, 기본값, 프로필 가져오기·내보내기를 지원합니다. 월드 크기는 1배가 100%이며, 눈 간격과 이동 속도의 자동 연동을 각각 선택할 수 있습니다. 시각 효과는 게임 기본값을 사용하고 개별 효과 스위치는 제공하지 않습니다.

설정을 저장하려면 게임을 종료하고, 저장 후 직접 게임을 다시 실행하세요.

## 현재 상태

| 구분 | 확인한 범위 |
|---|---|
| 데스크톱 도구 | 설정 저장·프로필·다국어, 설치·삭제·중단 복구, 업데이트 보호 등 647개 검사 통과 |
| 실제 GUI | 세 언어, 최소 창·확대 배치, 인스톨러 설치·삭제 작업 6회 확인 |
| 게임 내 VR | 일부 장면·기능을 실기로 확인했으며, 전체 장면·전환과 최신 기능의 동작 확인은 별도 |
| GitHub 배포 | 비공개 소스·문서 게시. 최신 전체 설치 패키지 배포와 실제 정식 릴리스 업데이트 검증은 아직 |

데스크톱 검사는 격리된 테스트 폴더에서 수행했습니다. 실제 게임 폴더에서는 파일 무결성과 설정 프로그램 연결을 읽기 전용으로 확인했으며, 게임 파일과 사용자 설정을 변경하지 않았습니다. 자세한 조건은 [검증 결과](docs/ko/VERIFICATION.md)를 참고하세요.

## 주의 사항

- 게임과 SteamVR는 직접 실행합니다. 실제 VR 동작은 설치·저장 성공과 별도로 확인해야 합니다.
- 설치·업데이트·삭제 전에는 게임을 종료하세요. 수정되거나 알 수 없는 파일을 강제로 덮어쓰지 않습니다.
- 문제가 생기면 인스톨러의 작업 로그를 확인하고, 상황에 따라 중단 복구 또는 기록된 이전 버전 복원을 사용하세요.
- 비공개 저장소의 자동 업데이트는 본인용 접근을 전제로 합니다. 인증·네트워크·검증 실패 시 기존 설정과 설치를 유지하며, 실제 정식 릴리스 다운로드는 아직 검증하지 않았습니다.
- 현재 소스만으로 전체 네이티브 VR 모드를 재빌드할 수는 없습니다. 소스에 포함된 설치 계약은 비작동 템플릿이므로 실제 게임 폴더에 복사하지 마세요.

게임 원본 파일, 사용자 설정, 로그, 복구 자료와 인증 정보는 이 저장소에 포함하지 않습니다. 프로젝트 소스의 배포 라이선스는 아직 정하지 않았으며, 포함된 [Microsoft .NET 고지](DOTNET-NOTICES.txt)는 해당 외부 구성 요소에 대한 고지입니다.

> 이 프로젝트는 비공식 팬 프로젝트입니다. 게임과 관련된 상표·저작물의 권리는 각 권리자에게 있으며, 이용하려면 정식으로 설치한 게임이 필요합니다.
