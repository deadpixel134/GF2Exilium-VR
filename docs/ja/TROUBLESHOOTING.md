# 問題が発生したとき

[한국어](../ko/TROUBLESHOOTING.md) · [English](../en/TROUBLESHOOTING.md) · [日本語](TROUBLESHOOTING.md) · [简体中文](../zh-CN/TROUBLESHOOTING.md)

## 1.1.6 — 自動更新の修正

設定GUIの起動時に公開GitHubリリースを確認します。通知の **更新** を承認するとダウンロード・検証・インストールします。1.1.6以降はGitHub CLIのインストールやログインが不要です。

旧クライアントの固定許可リストが新しいビルドを拒否する問題を修正しました。クライアントはリリース・ファイルのハッシュ、種類、現在の所有権を確認し、検証済みの新インストーラーが最終ビルド検証・バックアップ・インストールを担当します。Clean・Dirtyの種類と設定は維持します。

1.1.4以前では今回一度だけ、希望するClean・Dirty ZIP全体を新しいフォルダーに展開し、付属の新しいGF2VR.Installer.exeで更新してください。更新確認が動作する1.1.5環境ではGUI更新を利用できます。旧版に必要なGitHub CLIがない場合も今回一度ZIPから更新してください。1.1.6導入後はCLI・ログイン不要でGUIから更新できます。

VR DLLは1.1.5と同一です。ログの初期値OFF、明示的ON設定と初回整理の除外、パネル・接触設定を維持します。インストール前にゲームと設定画面を閉じてください。

## 1.1.5 — ログ記録設定

Clean・Dirty共通で設定GUIに **診断 → ログを自動記録** を追加しました。初期値は **OFF** で、旧設定に項目がない場合もOFFです。保存後にゲームを再起動すると適用されます。

初回の更新インストール時に、ログOFFのユーザーの以前のVR自動ログを一度だけ整理します。**ログONのユーザーは既存ログを保持し、この初回整理から除外されます。** 後でOFFに変えても過去のログを遅れて削除しません。設定・他のMOD・手動で収集した資料は保持します。

問題の調査時にログを有効にしてください。ONでは同じビルドのログに追記され、容量が増加することがあります。

1.1.5では必要なCleanまたはDirtyのZIP全体を新しいフォルダーに展開し、付属の新しいGF2VR.Installer.exeで更新してください。旧設定アプリは新しいnativeプロファイルを拒否する場合があります。既存設定は保持されます。

> **必須: VR を使用する前に、ゲーム設定のアンチエイリアスをオフにしてください。**

1.1.3 は PR #1 の 3DMigoto 既定 wrapper モードとの互換性変更を Clean・Dirty の両方に反映します。ゲームの wrapper を保持し、VR コピーと OpenXR には実際の D3D11 デバイス/context を使用します。DLL と一致する設定アプリ・インストーラーを同梱します。

## 1.1.1 — Clean / Dirty

| 機能 | Clean | Dirty |
|---|---|---|
| 通常の VR・立体表示・コントローラー入力・設定 | 含む | 含む |
| 両手の位置を示す白い球 | 含む | 含む |
| キャラクターの胸への接触・変形 | 含まない | 含む |

通常の VR のソース・バージョン・更新は両方で共通です。接触変形コードは Dirty のみで、Clean は単に機能をオフにしたものではなく実装を除外しています。

インストール・切替・削除ではユーザー設定を保持します。任意の touch_interaction.json は Dirty のみ使用します。削除時は記録された直前のインストールがあれば復元し、それ以外は所有ファイルだけを削除します。変更済み・所有権不明の DLL は上書きせず保持します。version.dll だけをコピーしたり、別パッケージのファイルを混ぜたりしないでください。

Quest 3 と Galaxy XR で報告された左右映像のずれは、アンチエイリアスが原因であると確認されました。VR を使用する前に、ゲーム設定のアンチエイリアスをオフにしてください。

以下は旧版から維持する詳細案内です。現在のダウンロードと検証範囲は上の 1.1.1 説明を優先してください。


まず、どの作業で問題が発生したか確認してください。設定の保存、インストール・更新、実際の VR 画面・入力のどれに関する問題かによって、確認する箇所が異なります。

## ゲームフォルダーが見つからないと表示される

**GF2_Exilium.exe があるフォルダー**、またはそれを含むインストール先を選択してください。フォルダー名や階層が異なっても実行ファイルを探します。複数見つかった場合は、対象のゲームに近いフォルダーを選択してください。 検索先が広すぎて完了できない場合は、実行ファイルに近いフォルダーを指定してください。ゲームフォルダーと ZIP の展開先を取り違えないようにしてください。

## パッケージファイルがない・インストールできないと表示される

- ZIP の内容を先にすべて展開したか確認します。
- 実行ファイルだけを移動していないか確認します。
- GitHub のコードダウンロード ZIP を、インストールファイルとして使っていないか確認します。
- [1.0.2 リリース](https://github.com/deadpixel134/GF2Exilium-VR/releases/tag/v1.0.2)のインストール ZIP を使ってください。元ゲームの SHA-256・サイズ・キャッシュの違いでは止めませんが、製品パッケージの破損・ハッシュ不一致はインストールを止めます。

ファイルが不足・破損している場合は、リリース ZIP を再度ダウンロードし、新しいフォルダーにすべて展開してください。インストーラーが拒否したファイルを任意に編集して、検査を通そうとしないでください。

## ファイルの変更や所有記録の欠落が表示されます

これは元ゲームのバージョンや SHA-256 のエラーではありません。既存の `version.dll` がインストール記録と異なるか、手動コピーなどにより所有記録がないため、ファイルを保護したという意味です。1.0.2 では記録がなくても、現在のパッケージがインストールするファイルと内容が完全に一致すれば、バックアップしてインストールできます。削除時は元のファイルを復元します。異なる DLL や変更済みファイルは引き続き保護します。記録とバックアップを削除せず、既存 MOD の削除方法を確認してください。旧版を手動コピーした場合など、現在のパッケージと内容が異なるファイルは自動で引き継ぎません。

## ヘッドセットに映像が出ない・周期的に途切れる

SteamVR/OpenXR とヘッドセットの接続状態を確認し、ゲームを完全に終了してから、普段の方法で起動し直してください。PC のゲーム画面も同時に止まるか確認すると、原因を絞る手がかりになります。

画質倍率を上げてから発生した場合は、最後に正常に動作していた値に戻してください。1.0.0 には、活動層の周期的な引っ掛かりを引き起こしていた、カメラ警告の反復処理を修正したコードが含まれています。引き続き発生する場合は、シーン、繰り返しの間隔、PC 画面と HMD のどちらが途切れるかを併せてお知らせください。機器ごとの一定のフレームレートを保証するものではありません。

## 「設定を開く」ボタンが無効になっている

現在のゲームに対応する設定プログラムが見つからない状態です。ゲームフォルダーが正しいか確認し、**再確認**を押してください。設定プログラムだけ、またはインストーラーだけを個別にコピーした場合は、同梱ファイルが不足している可能性があります。

実行パスが案内されている場合は、そのパスから開いてみてください。解決しない場合は、プログラムとインストールファイルを混在させる前にエラーの案内を確認してください。

## 保存やインストールができない

まず、ゲームが完全に終了していることを確認します。ウィンドウを閉じても、ゲームがまだ実行中の場合があります。

数値エラーが表示されたら、入力欄に単位や文字を含めていないか確認してください。小数点にはピリオドを使います。値が大きすぎたり、機器で処理できなかったりする場合は、以前の値または初期値に戻してください。

ファイルアクセスエラーが表示されたら、表示されたフォルダーが正しいか、他のプログラムがそのファイルを使用していないか確認してください。変更済みのファイルを保護するために処理が止まった場合は、まずそのファイルをバックアップし、どのような変更があったか確認します。

## 保存してもゲームで変わらない

保存後にゲームを終了して再起動したか確認します。プロファイルの読込や初期値への変更後も、**保存**が必要です。

右スティックの押し込みで変更したカメラ追従は、現在のゲーム実行中にのみ適用されます。次回起動時の状態を変更するには、設定プログラムで保存する必要があります。

## 補助パネル・クリック・スティック操作が想定と異なる

1. コントローラーが正常に接続されているか確認します。
2. PC 上でゲームウィンドウを選択します。
3. 設定で、移動・回転の手やパネル・ポインターの手を変更していないか確認します。
4. 補助パネル側の手の Trigger を押している場合は、離してみてください。押している間は WASD ゲーム操作モードになります。
5. スナップ回転は、スティックを中央に戻してから再び倒します。

補助パネルは、3D 画面でパネル側の手の Grip を使って開閉します。通常の 2D 画面の正面パネルは、この操作で非表示にはなりません。[操作方法](USAGE.md)を参照してください。

## ワールドグリップで動かない

この機能は既定ではオフです。設定で有効にし、起動ボタンと追跡する手をそれぞれ 1 つ以上選択してから保存し、ゲームを再起動したか確認します。

別のパネル・UI 操作が優先される組み合わせの場合は、既定の右 Grip と右手の追跡で試してください。押していたボタンは、一度離してから押し直します。

## 更新を確認できない

インターネット接続、GitHub CLI のインストール・ログイン状態、新しい正式版が実際に公開されているかを確認します。公開の[リリースページ](https://github.com/deadpixel134/GF2Exilium-VR/releases)から ZIP を直接ダウンロードして更新することもできます。更新の確認に失敗しても、既存のインストールは維持されます。[更新ガイド](UPDATE.md)を参照してください。

1.0.0 からは 1.0.2 ZIP を直接ダウンロードし、同梱の新しいインストーラーで更新してください。古い設定プログラムがパッケージを拒否しても、この手順で設定とインストール記録を維持できます。

## インストールが止まった・新しいバージョンで問題が発生した

ゲームを終了し、同じフォルダーを指定してインストーラーを再度開きます。中断された作業がある場合は、**中断からの復元**を使用します。更新完了後に問題が発生した場合は、前のバージョンへの復元案内を確認します。[削除・復元ガイド](INSTALLATION.md)を参照してください。

## 問題を報告するとき

押したボタン、発生までの手順、エラーメッセージ、使用しているヘッドセットと接続方法を併せてお知らせください。インストールに関する問題では、作業ログに最後に表示された内容が役立ちます。

画面やファイルを共有する前に、アカウント情報や認証情報が含まれていないか確認してください。元のゲームファイルを丸ごと送る必要はありません。
