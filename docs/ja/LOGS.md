# ログの保存と送付

[한국어](../ko/LOGS.md) | [English](../en/LOGS.md) | [日本語](../ja/LOGS.md) | [简体中文](../zh-CN/LOGS.md)

[トップ](../../README.ja.md)

問題を報告するときに VR MOD の診断ログを添えていただくと、原因の特定に大きく役立ちます。ログ記録は初期状態でオフなので、次の手順で有効にし、問題をもう一度再現してからファイルを送ってください。

## 1. ログの保存を有効にする

1. ゲームを終了します。
2. 設定プログラムを開きます。インストーラーの **設定を開く** を押すか、ゲームフォルダーの `vrmod/bin/GF2VR.Configurator/GF2VR.Configurator.exe` を実行します。
3. **診断** タブで **ログを自動記録** にチェックを入れ、**保存** を押します。
4. ゲームをもう一度起動します。保存した設定はゲームを再起動すると適用されます。

## 2. 問題を再現する

- 問題が起きる画面まで進み、同じ症状を一度再現してからゲームを終了してください。
- ログはゲームを起動するたびに同じファイルの末尾へ追記され、1 回の起動で 100MB を超えることがあります。今回の問題だけを記録したい場合は、ゲームを起動する前に既存のログファイルを別のフォルダーへ移動してください。
- ゲームが突然終了した場合、最後の約 0.25 秒分は記録されないことがあります。

## 3. ログフォルダーを開く

- **1.3.3 から:** 設定プログラムの **診断** タブで **ログフォルダーを開く** を押すと、エクスプローラーでログフォルダーが開きます。ボタンの下に保存場所が表示されます。まだログが作成されていない場合は案内メッセージが表示されます。
- **手動で開く:** 設定プログラム上部の **ゲームフォルダー** に表示されているパスの下にある `vrmod\logs\bootstrap` フォルダーです。
  - Steam 版のように `GF2_Exilium.exe` がゲームフォルダー直下にある場合は `<ゲームフォルダー>\vrmod\logs\bootstrap` です。
  - Haoplay 版のように `GF2_Exilium.exe` が `GF2 Game` フォルダーの中にある場合は、`GF2 Game` の親フォルダーの下の `vrmod\logs\bootstrap` です。

## 4. 送るファイルを選ぶ

- `GF2VR-CLEAN-` または `GF2VR-DIRTY-` で始まる `.jsonl` ファイルのうち、**更新日時がいちばん新しいファイル** を選んでください。同じ名前の `.inventory.jsonl` ファイルがあれば一緒に送ってください。
- ファイル名はバージョンによって変わります。たとえば 1.3.3 では Dirty が `GF2VR-DIRTY-133-006.jsonl`、Clean が `GF2VR-CLEAN-130-002.jsonl` です(1.3.1 の Dirty は `GF2VR-DIRTY-130-004.jsonl`)。
- 選んだファイルを ZIP に圧縮してください。Windows 11 は右クリック → **圧縮先** → **ZIP ファイル**、Windows 10 は右クリック → **送る** → **圧縮 (zip 形式) フォルダー** です。テキストのログなので大きく縮みます(例: 約 100MB → 約 5MB)。

## 5. 開発者に送る

- [GitHub Issues](https://github.com/deadpixel134/GF2Exilium-VR/issues/new) で新しい Issue を作成し、ZIP ファイルを入力欄にドラッグして添付してください。GitHub の添付ファイルは 25MB までです。
- または [Arca Live VR チャンネル](https://arca.live/b/vrshits) に投稿してください。
- ファイルが大きすぎる場合は、Google Drive などのクラウドストレージにアップロードし、共有リンクを記載してください。
- 次の内容も一緒に書いてください。
  - 種類(Clean/Dirty)とバージョン、Haoplay/Steam
  - ヘッドセットと接続方法(例: Quest 3 + Virtual Desktop)
  - 問題が起きた画面、再現手順、表示されたエラーメッセージ
  - 問題が起きたおおよその時刻

## 6. 共有する前に

- GitHub の Issue と Arca Live の投稿は誰でも閲覧できます。
- ログは VR MOD の動作記録(イベント・状態・性能の数値)です。ログファイルだけを送り、ゲームの元ファイル、アカウントや認証情報、依頼されていない他のファイルは送らないでください。

## 7. 終わったらオフにする

確認が終わったら **診断** タブの **ログを自動記録** のチェックを外して保存してください。オンのままにするとログファイルが大きくなり続けます。送付済みのログファイルは削除してもかまいません。
