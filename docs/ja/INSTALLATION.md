# インストール・削除・復元

[한국어](../ko/INSTALLATION.md) · [English](../en/INSTALLATION.md) · [日本語](INSTALLATION.md) · [简体中文](../zh-CN/INSTALLATION.md)

[正式版 1.0.1](https://github.com/deadpixel134/GF2Exilium-VR/releases/tag/v1.0.1)から **GF2VR-Native-SelfContained-1.0.1.zip** をダウンロードしてください。GitHub の **Source code** ZIP はインストール用ではありません。

## インストール前の準備

- Windows x64 PC に正規のゲームと VR 環境が必要です。**2.0.3936** は実機確認の基準ビルドです。元のゲームの SHA-256・ファイルサイズ・キャッシュの違いだけでインストールを止めませんが、他のゲームバージョンでの VR 動作を保証するものではありません。
- ゲームを完全に終了します。
- ダウンロードした ZIP の内容をすべて新しいフォルダーに展開します。ZIP の中から直接実行しないでください。
- インストーラーの実行ファイルだけを移動せず、同梱されているファイルとフォルダーをそのまま維持します。

必要な .NET ランタイムはインストールパッケージに含まれています。ゲーム・ヘッドセット用ソフトウェア・SteamVR は別途用意してください。

## インストールする

1. 展開したフォルダーで **GF2VR.Installer.exe** を実行します。
2. **ゲーム**の右側にある **参照…** を押します。**GF2_Exilium.exe があるフォルダー**、またはそれを含むインストール先を選択してください。フォルダー名や階層が異なっても実行ファイルを探します。複数見つかった場合は、対象のゲームに近いフォルダーを選択してください。
3. **パッケージ**が空欄の場合は、ZIP を展開したフォルダーを選択します。インストーラー、package-manifest.json ファイル、payload フォルダーが同じ場所にあることを確認してください。ファイルを直接編集する必要はありません。
4. 表示されたバージョンと処理対象のファイル一覧を確認します。**設定プログラムのみをインストールする旨の案内**が出る場合、そのパッケージは VR MOD 全体をインストールするものではありません。
5. **インストール**を押し、表示された場所が正しければ確認します。現在のインストール状態によっては、**更新**または**再インストール**と表示されます。
6. 完了メッセージが出るまで待ちます。作業が終わったら、**設定を開く**から設定プログラムを開けます。

処理中にインストーラーを閉じたり、インストールファイルを移動したりしないでください。完了後、ゲームと SteamVR は手動で起動します。先に設定を確認する場合は、[設定ガイド](SETTINGS.md)を参照してください。

別のプログラムの version.dll がある場合や、製品パッケージのハッシュ・所有権検査に失敗した場合は、インストールを拒否することがあります。元ゲームのハッシュの違いだけでは拒否しません。既存ファイルの上書き・削除で保護を回避せず、[トラブルシューティング](TROUBLESHOOTING.md)を確認してください。

標準の `GF2 Game/GF2_Exilium.exe` 構成では、従来どおり親フォルダーの `vrmod` を使います。それ以外の構成では、見つかった実行ファイルのフォルダーにある `vrmod` を使います。`version.dll` は常にその実行ファイルの隣にインストールされます。

## 画面のボタン

| ボタン | 機能 |
|---|---|
| インストール・更新・再インストール | 選択したインストールファイルをゲームフォルダーに適用します。 |
| 設定を開く | 現在のインストールに対応する設定プログラムを開きます。利用できない場合は無効になります。 |
| 再確認 | 選択したフォルダーとインストール状態を再確認します。 |
| 削除 | インストーラーがインストールしたファイルを処理します。前のバージョンが残っていれば、そのバージョンに戻せます。 |
| 中断からの復元 | インストールや削除が途中で止まった場合に、以前のファイル状態へ復元します。 |

## 削除する・前のバージョンに戻す

ゲームを終了し、インストーラーでゲームフォルダーを確認してから削除関連のボタンを押します。前のバージョンが保管されていれば、**直前の版に戻す**と表示されます。画面の確認メッセージを読んで進めてください。

初回インストールの状態から削除すると、インストーラーが管理するファイルだけを削除し、ユーザー設定と他の MOD のファイルは残します。前のバージョンへ復元した場合は、MOD を完全に削除した状態とは異なります。

変更されたファイルが原因で処理が拒否された場合は、ファイルを強制的に削除せず、[トラブルシューティング](TROUBLESHOOTING.md)を確認してください。

## 作業が途中で止まった場合

1. ゲームが終了していることを確認します。
2. 同じゲームフォルダーを指定してインストーラーを再度開きます。
3. **中断からの復元**が有効なら実行します。
4. 結果を確認してから、インストールまたは削除をやり直します。

**中断からの復元**は停止した作業を復旧する機能で、**前のバージョンへの復元**はインストールされていたバージョンへ戻す機能です。復元に失敗した場合は、繰り返しファイルを変更する前に、エラーメッセージと作業ログを確認してください。
