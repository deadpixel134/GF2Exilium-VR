# 設定プログラムの使い方

[한국어](../ko/SETTINGS.md) | [English](../en/SETTINGS.md) | [日本語](../ja/SETTINGS.md) | [简体中文](../zh-CN/SETTINGS.md)

[トップ](../../README.ja.md)

インストーラーの**設定を開く**から設定プログラムを開きます。インストール済みゲームフォルダーの `vrmod/bin/GF2VR.Configurator/GF2VR.Configurator.exe` から直接開くこともできます。実行ファイルと一緒にインストールされたファイルは、同じフォルダーに維持してください。表示言語は下部の **한국어 / English / 日本語** ボタンで変更でき、選択は保存されます。

## 変更した設定を適用する

1. ゲームを終了します。
2. 希望の項目を調整します。項目の下にある説明も確認してください。
3. **保存**を押し、完了メッセージを確認します。
4. ゲームを手動で再起動します。

設定画面で数値を変更するだけでは、実行中のゲームにすぐ反映されません。数値には単位を付けず、小数点にはピリオドを使ってください。例えば 0.5 と入力します。

## 画質・立体感

**VR レンダー解像度倍率**は、VR 映像を描画する解像度です。値を上げると鮮明になる可能性がありますが、性能とメモリへの負荷も増えます。下げると映像がぼやける場合があります。PC 画面や補助パネルの解像度を変更する設定ではありません。

初期値は 1.0 です。問題が発生した場合は、以前正常に動作していた値に戻してください。すべての機器で同じ値を適用できるとは限りません。視覚効果はゲームの既定値を使用し、効果ごとのオン・オフ項目はありません。

## ワールドの大きさ

**ワールド倍率**は、周囲の世界が感じられる大きさを調整します。**1 は 100%、2 は 200%、0.5 は 50%** です。200% に設定する場合は、数値の 2 を入力してください。

| 設定 | 説明 |
|---|---|
| ワールド倍率 | 世界の大きさを調整します。初めは初期値の 1 から少しずつ変更してください。 |
| Stereo Depthをワールド倍率に連動 | ワールドの大きさに合わせて、ゲーム内の両眼間隔を自動調整します。初期値はオンです。 |
| Stereo Depth／両眼間隔倍率 | 立体感を決めるゲーム内の両眼間隔を手動調整します。自動連動中は現在値の表示のみで、直接編集できません。 |
| 移動速度をワールド倍率に連動 | 世界を大きくするとその分移動を速く、小さくするとその分遅く調整します。初期値はオンです。 |

両眼間隔の自動連動をオフにすると、その時点の計算値を出発点として手動調整できます。再びオンにすると、現在のワールドの大きさに合わせて自動計算します。この設定は、ヘッドセット自体の両眼間隔調整に代わるものではありません。

移動速度の連動をオフにしても、**移動・回転**タブの基本速度と手動倍率は維持されます。ワールドの大きさに応じた自動調整だけが外れます。

画面下部の**頭の移動**表示は、ワールドの大きさに合わせて頭の動きを補正した値です。スティックの移動速度ではなく、個別に入力する項目でもありません。

## 移動・回転

| 設定 | 説明 |
|---|---|
| スティック移動を有効化 | コントローラーのスティックで VR 視点を移動するかを設定します。 |
| 移動に使用する手 | 初期値は左手です。変更すると移動と回転のスティックの役割が入れ替わります。 |
| スティック回転を有効化 | 反対の手のスティックで視野を回転するかを設定します。 |
| 回転方式 | スナップは一定角度ずつ回転し、スムーズはスティックを倒している間、連続して回転します。 |
| 移動速度 | スティックで移動する基本速度です。初期値は 1.0 です。 |
| 移動速度の手動倍率 | 基本移動速度をどれだけ速く、または遅くするかを調整します。1.0 はそのまま、2 は 2 倍、0.5 は半分です。 |
| スナップ角度 | スナップ方式で一度に回転する角度です。初期値は 30° です。 |
| スムーズ回転速度 | 連続回転の速さです。スナップ方式では使いません。 |
| スティックのデッドゾーン | スティックの小さな揺れを無視する範囲です。手を離しても動く場合は、この項目を確認してください。 |
| 起動時にゲームカメラへ追従 | ゲーム起動時に元のカメラの動きに追従するかを設定します。初期値はオンです。 |

移動に使う手の変更と、**ボタン**タブのパネル・ポインターの手の交換は、別々の設定です。

実行中に**右スティックの押し込み**でカメラ追従を切り替えても、保存済みの起動時設定は変わりません。次回起動時も同じ状態にするには、この画面で保存してください。

## ワールドグリップ

ワールドグリップは、ボタンを押したまま手を動かして VR 視点を移動する機能です。既定ではオフなので、使う場合は先に有効にしてください。

- **World Drag を有効化**: 機能をオン・オフします。
- **起動ボタン**: 左右の Grip または Trigger から、使うボタンを選択します。
- **追跡する手**: どちらの手の動きを基準にするか選択します。

起動ボタンと追跡する手は、それぞれ 1 つ以上選択する必要があります。初期選択は右 Grip と右手の追跡です。

補助パネルを担当する手の Grip は、パネルの開閉が優先されます。同じ手の Trigger はゲーム操作モードに使用され、ポインター側の Trigger は UI 操作が優先されます。初めは既定の右 Grip の組み合わせで使い方を覚えると分かりやすくなります。

## 手の表示

白い球状の両手表示は Clean・Dirty 共通で、初期状態は ON です。手の表示タブで調整します。Clean にキャラクターの接触変形は含まれません。

## 補助パネル — 共通

ユーザーの方を向く設定と、その間も手動角度を適用するかを別々に選択できます。手動角度の併用をオフにすると、ユーザー向きを切った時だけYaw/Pitch/Rollと画面の傾きを適用します。無効中の値も保持し、位置と最大幅・高さは常に適用します。最大サイズ内で元の縦横比を維持します。

初期値: ユーザー向きON、手動角度の併用OFF。位置X/Y/Z = 0 / -0.10 / 0.01m、Pitch/Yaw/Roll = -67 / 3 / 0度、画面の傾き45度、最大幅・高さは各0.66m。

位置はコントローラーのローカル軸に従います。観察された通常の持ち方では+X右 / +Y前 / +Z上で、手を回すと移動軸も回転します。画面の傾きは最終画面の横軸を基準に正で上向き、負で下向きです。auxiliaryPanelオブジェクトがない既存設定は、パネル設定や初期値を適用するまで従来の配置を保持します。

## 接触フィードバック — Dirty

手の表示タブで接触振動の強さ・時間を調整します。初回接触で1回振動し、完全に離して再接触すると再動作します。初期値15% / 30ms、0で無効です。

接触の揺れタブでは胸・臀部を別々に調整します。以下の順序は強さ / 持続 / 範囲 / 傾き / 伸びです。

| 部位 | 初期値 |
|---|---|
| 胸 | 40% / 0.4倍 / 75% / 50% / 45% |
| 臀部 | 120% / 0.5倍 / 120% / 120% / 140% |

保存済みの明示値を保持し、部位別の値が旧共通値より優先されます。任意の上限を廃止し、有限数・正の持続値・正の圧縮スケールなど必須検査は維持します。保存後にゲームを再起動してください。

## 活動層 UI

**主画面に活動層 UI を表示**をオフにすると、主 VR 画面に重なって表示される活動層 UI を非表示にします。3D 画面と、元のゲーム画面を表示する補助パネルは維持されます。

オンの場合でも、補助パネルを開くと主画面の UI は一時的に非表示になり、補助パネルを閉じると再び表示されます。

## ボタン

| 設定 | オフ: 既定 | オン |
|---|---|---|
| クリックと戻るボタンを交換 | ポインター側の手の A または X でクリック、B または Y で戻る | 2 つの動作を入れ替えます。 |
| パネルとポインターの手を交換 | 左手が補助パネル、右手がポインター | 右手が補助パネル、左手がポインター |

パネルを担当する手を変更すると、パネルを開閉する Grip とゲーム操作モードの Trigger もその手に移ります。スティックの移動・回転に使う手は、この設定では変わりません。

ゲーム操作モードの **X/A → F、Y/B → Escape** 入力は、通常のクリック・戻るボタンの交換とは別です。

## 診断とログ

**診断 → 自動ログ記録**の初期値は OFF です。調査が必要な場合に ON にして保存し、ゲームを再起動します。ON ではログの容量が増え続けることがあります。

1.3.3 から、同じタブの **ログフォルダーを開く** でログの保存フォルダーを直接開けます。保存場所はボタンの下に表示されます。ログの送り方は [ログの保存と送付](LOGS.md) を参照してください。

更新時に対象となる既存の VR 自動ログを一度だけ整理します。明示的に ON の利用者は既存ログを保持し、この初回整理から除外されます。後で OFF にしても、その過去ログを遅れて削除しません。設定・他 MOD・手動収集資料は保持します。

## 保存・プロファイルのボタン

| ボタン | 使い方 |
|---|---|
| 保存 | 現在編集した設定を保存します。適用するにはゲームを再起動してください。 |
| 再読込 | 最後に保存した設定を再び読み込みます。未保存の変更は失われます。 |
| 初期値 | 設定項目を初期値に戻します。適用するには続けて保存してください。 |
| 書出 | 現在の設定を別のプロファイルファイルに保存します。複数の組み合わせを切り替えたり、バックアップしたりするときに使えます。 |
| 読込 | 保存済みプロファイルを読み込みます。内容を確認した後に保存することで、ゲーム設定に反映されます。 |

数値の横にある推奨範囲は、調整を始める際の目安です。範囲外の入力が一律に禁止されているわけではありませんが、機器や機能が処理できない値は適用されない場合があります。エラーが出たらメッセージを確認し、以前の値または初期値に戻してください。
