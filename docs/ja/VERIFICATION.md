# 確認済みの動作と制限事項

[한국어](../ko/VERIFICATION.md) · [English](../en/VERIFICATION.md) · [日本語](VERIFICATION.md) · [简体中文](../zh-CN/VERIFICATION.md)

正式版 1.0.0 の対応対象と確認範囲を記載します。現在の実装に対するユーザーの実機確認、配布ファイルのローカル検証、他の PC での確認は区別しています。

## 対応対象

Windows x64 PC 用の GF2 Exilium **2.0.3936** が対象で、インストーラーが元のゲームファイルの指紋を確認します。ゲームの更新でファイルが変わった場合、新しい互換リリースが必要になることがあります。すべての HMD・コントローラー・接続方法に対する互換性一覧は提供していません。

## 設定プログラムとインストーラー

独立したテスト用フォルダーで、以下の動作を確認しました。

- 設定の保存・再読込、初期値、プロファイルの読込・書出
- 不正な設定値に対するエラー案内と、言語選択の維持
- インストール・更新・削除、前のバージョンへの復元、中断からの復元
- 既存の設定や他のファイルを維持する動作
- 進捗・作業ログ、インストーラーが対応する設定プログラムを見つける動作
- 3 言語の画面と、小さいウィンドウ・拡大したレイアウトでのボタンの位置

この検査では、実際のゲームファイルやユーザー設定を変更していません。

## 現在の実装の実機確認

対応シーンの立体映像、補助パネルと UI 操作、スティック移動・回転、ワールドグリップ、活動層 UI の表示設定、ゲーム操作モードの WASD・F・Escape 入力を実機で確認してきました。ワールドの大きさとの連動、左スティック押し込みによる視点復帰、右スティック押し込みによるカメラ追従、現在の設定・インストーラー画面を含む実装は、ユーザーのテスト完了確認をもとに正式版として固定しました。

活動層で 2～4 秒ごとに報告されていた引っ掛かりに関連し、カメラ警告を繰り返し発生させていた呼び出しを修正しました。その後のゲームログでは該当する警告は発生せず、ユーザーは現在の実装を安定版として選択しました。測定した最低フレームレートや、あらゆる状況で途切れない動作を保証するものではありません。

## 配布ファイルの検証と限界

配布用のネイティブモジュールは、上記実装の描画・入力コードを維持しながら、ゲームのインストールフォルダーを基準にファイルを探すよう構成しました。パスの移動、Windows API の呼び出し、エクスポート項目、ファイルの整合性をローカルで検査しました。この配布用バイナリ自体を、新たにゲーム/HMD で実行した結果は別途記録していません。

必要な .NET ランタイムを同梱していますが、.NET が入っていない新しい Windows PC で、インストールから HMD の起動までを一通り新たに検証したわけではありません。すべてのシーン遷移やボタンの組み合わせも網羅していません。

## 更新と配布

パッケージ検査・インストール・更新・前のバージョンへの復元は、テスト用フォルダーで確認しました。1.0.0 は最初の正式リリースなので、その後の正式版への実際のユーザー更新完了の記録はまだありません。新しいバージョンをダウンロードして適用する際にも、既存のインストール検査と復元手順を使用します。

問題が発生した場合は、シーン・操作・機器環境とエラーメッセージを、[トラブルシューティング](TROUBLESHOOTING.md)に従ってまとめてください。ダウンロードについては、[リリースガイド](RELEASE_READINESS.md)を参照してください。
