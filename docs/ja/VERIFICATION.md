## 1.1.5 — ログ記録設定

Clean・Dirty共通で設定GUIに **診断 → ログを自動記録** を追加しました。初期値は **OFF** で、旧設定に項目がない場合もOFFです。保存後にゲームを再起動すると適用されます。

初回の更新インストール時に、ログOFFのユーザーの以前のVR自動ログを一度だけ整理します。**ログONのユーザーは既存ログを保持し、この初回整理から除外されます。** 後でOFFに変えても過去のログを遅れて削除しません。設定・他のMOD・手動で収集した資料は保持します。

問題の調査時にログを有効にしてください。ONでは同じビルドのログに追記され、容量が増加することがあります。

1.1.5では必要なCleanまたはDirtyのZIP全体を新しいフォルダーに展開し、付属の新しいGF2VR.Installer.exeで更新してください。旧設定アプリは新しいnativeプロファイルを拒否する場合があります。既存設定は保持されます。

## 1.1.4

両native DLLはソース再ビルドとバイト単位で一致します。native配置・設定4,517件、GUI Clean706件/Dirty941件、部位別初期値と直前の実ILの明示設定一致236件、実GUI初期値JSON236件、インストール・切替・失敗復元159件、直前インストールの正確な復元11件を通過しました。bridge131メソッド、接触hot IL46メソッドを検査しました。オフライン・非実行fixture・個人環境へのインストール検査であり、新たなゲーム/HMD実行の受入結果とはしません。


> **必須: VR を使用する前に、ゲーム設定のアンチエイリアスをオフにしてください。**

PR 作者は Dirty 開発ビルドで 3 回連続起動し、VR とスキンの同時動作を確認したと報告しています。これは投稿者の記録であり、新しい 1.1.3 バイナリの HMD 受け入れ確認ではありません。本リリースでは両 native ビルド、実際の変更ソースを使う COM 同一性/失敗経路、デスクトップビルド、パッケージ整合性を検証します。新たなゲーム/HMD 実行は行っていません。

Quest 3 と Galaxy XR で報告された左右映像のずれは、アンチエイリアスが原因であると確認されました。VR を使用する前に、ゲーム設定のアンチエイリアスをオフにしてください。

3DMigoto 既定 wrapper モードとの互換性変更と一致するビルドメタデータを追加します。通常 VR と手の表示は共通、接触変形は Dirty 専用です。既存設定と所有権/復元保護を保持します。
