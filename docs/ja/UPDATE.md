## 設定プログラムから更新

通常の **1.1.6 以降の管理されたインストール**は、設定プログラムの起動時に公開 GitHub リリースを確認します。通知の**更新**を承認するとダウンロード・検証・インストールを行います。現在の更新経路に GitHub CLI やログインは不要です。

インストール前にゲームを終了し、アプリの終了案内に従ってください。更新確認の失敗だけで既存のインストールが変わることはありません。

## 通知が来ない・更新に失敗する場合

1. [最新リリース](https://github.com/deadpixel134/GF2Exilium-VR/releases/latest)から現在と同じ Clean または Dirty の**完全な ZIP**を取得します。
2. 新しいフォルダーにすべて展開します。異なるパッケージを混ぜないでください。
3. ゲームと既存の設定・インストーラーを終了します。
4. 新しい ZIP の `GF2VR.Installer.exe` で既存のゲーム場所と種類を確認してインストールします。

1.1.4 以前や、古い更新機能が確認できない環境も一度この方法で更新できます。接続できない旧クライアントには、新しいファイルの公開だけでは通知できません。

## 設定の保持と復旧

同じ種類の更新では互換性のある設定とインストール記録を保持します。Clean↔Dirty の切り替えは希望する種類の完全な ZIP とインストーラーを使用します。整合性・所有権・実行中ゲームの検査で拒否された場合は回避せず、[問題解決](TROUBLESHOOTING.md)を確認してください。中断復旧や前のインストールの復元は[インストール案内](INSTALLATION.md)に従います。
