# 更新方法

[한국어](../ko/UPDATE.md) · [English](../en/UPDATE.md) · [日本語](UPDATE.md) · [简体中文](../zh-CN/UPDATE.md)

現在の正式版は **1.0.1** です。フォルダー構成や元ゲームの指紋の違いでインストールできなかった問題を改善します。リリース ZIP をダウンロードし、インストーラーで更新してください。ソースや文書の変更だけでは、インストール済みのプログラムは更新されません。

**1.0.0 からの更新は、1.0.1 ZIP を直接ダウンロードし、新しく展開したフォルダーのインストーラーを使ってください。** 既存のゲームフォルダーを選択すると、設定とインストール記録を維持して更新します。古い設定プログラムは新しいパッケージ形式を拒否する場合があります。その場合もこの手動手順を使ってください。古い設定プログラムから今回の版への自動置換は未検証です。

## リリース ZIP で更新する

1. [リリースページ](https://github.com/deadpixel134/GF2Exilium-VR/releases)で、希望する正式版の **GF2VR-Native-SelfContained-バージョン.zip** をダウンロードします。
2. ゲームを終了し、新しい ZIP の内容をすべて別のフォルダーに展開します。
3. 新しいインストーラーで、既存のゲームフォルダーと新しいパッケージフォルダーを確認します。
4. 表示されたバージョンと**更新**の案内を確認し、進めます。
5. 完了後、**設定を開く**から既存の設定を確認し、ゲームを手動で起動します。

詳しい画面案内は、[インストール方法](INSTALLATION.md)を参照してください。ユーザー設定は保持されます。以前のファイルに一部の新しいファイルだけを混ぜてコピーする方法は避けてください。

## 設定プログラムから更新を確認する

この機能は、PC にインストールされた **GitHub CLI（gh）** とそのログイン状態を使用します。CLI を使用しない場合は、上記の公開 ZIP のダウンロードで更新してください。GF2VR の設定ファイルにトークンやパスワードを書く必要はありません。

## 更新通知が表示された場合

1. 設定プログラムを開き、新しいバージョンの通知があるか確認します。
2. ゲームが実行中なら終了します。
3. 更新ボタンを押し、案内されたバージョンを確認します。
4. 続行に同意したら、プログラムによるダウンロードと処理が終わるまで待ちます。
5. 設定プログラムが閉じて再び開いたら、結果を確認します。ゲームは手動で再起動してください。

更新ボタンは、利用可能な新しいバージョンが確認されたときに表示されます。ウィンドウが再び開かない場合やエラーが表示された場合は、従来の実行パスから設定プログラムまたはインストーラーを開き、状態を確認してください。

## 通知が表示されない場合

新しいバージョンが存在しない、現在のインストール方式が自動更新の対象ではない、リポジトリへのアクセスやインターネット接続を確認できない、といった可能性があります。更新ボタンがないことだけで、インストールが壊れているとは限りません。

1.0.0 から 1.0.1 に更新できます。すでに 1.0.1 で、より新しい正式版がなければ通知は表示されません。ドラフトやプレリリースは正式更新の対象に選択しません。

更新の確認やファイル検査に失敗した場合は、既存のインストールを維持する構成です。問題が繰り返される場合は、[トラブルシューティング](TROUBLESHOOTING.md)に従ってメッセージを確認してください。

## 中断した場合・前のバージョンに戻す場合

更新が中断した場合は、[中断からの復元](INSTALLATION.md)を使用してください。更新完了後のバージョンで問題が発生した場合は、インストーラーの直前の版に戻す案内を確認します。復元や削除の前にも、ゲームを終了してください。
