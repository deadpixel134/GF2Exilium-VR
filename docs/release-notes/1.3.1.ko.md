## 1.3.1 — 한국어

### VR 포즈 갱신

- 눈 렌더링 직전에 머리 자세를 다시 읽는 late re-locate를 기본으로 켭니다. 기존에는 프레임 시작 때 읽은 자세로 눈을 그렸지만, 이제 메인 스레드 대기 뒤에 다시 읽으므로 고개를 돌릴 때 화면이 머리를 따라오는 지연이 그만큼 줄어듭니다. 실기 측정 1회에서는 제출되는 자세가 Main 약 12ms, Activity 약 27ms 더 최신이었고, 장면이 무거워 대기가 길수록 효과가 큽니다. 재획득 비용은 프레임당 0.01ms 미만이며 실패하면 기존 자세를 사용합니다. 프레임 수나 실제 화면 표시 지연의 개선은 측정으로 확인되지 않았습니다.
- Settings의 **화질·입체감** 탭에 **눈 렌더 직전 머리 자세 재획득** 토글을 추가했습니다. 체크를 해제하고 저장하면 `performance.json`에 `"pose": { "lateRelocate": false }`가 기록되고, 게임을 다시 시작하면 1.2.2 이전 방식으로 동작합니다. 키가 없으면 켜진 것으로 동작합니다.

### 로그·설치 개선

- 로그 요약은 유실·쓰기 실패 카운터가 바뀌면 최소 1초 간격으로, 변화가 없어도 10초마다 기록합니다. 기록 오류 후 다음 로그 묶음이 진행되도록 수정했습니다. 크래시나 급작스러운 종료 때 마지막 약 0.25초 분량은 유실될 수 있습니다.
- 설치·업데이트·복구 설치는 내용이 같은 파일의 쓰기를 생략하고 수정 시각을 유지합니다. 설치 기록·백업·복원·설정 보존·무결성 검사는 유지됩니다. 단독 발행하지 않은 1.2.3의 설치 개선을 포함합니다.
- Settings와 Installer를 새 VR 실행 파일에 맞춰 갱신했습니다. Settings, 패키지와 설치 기록의 버전은 1.3.1입니다.
- 1.3.0은 토글 없이 잠시 공개됐다가 철회했으며, 그 내용은 1.3.1에 모두 포함됩니다. 1.3.0을 받은 경우 Settings의 안내에서 1.3.1로 업데이트하세요.

### 알려진 제한

- Main 화면에서 고개를 돌릴 때 지연·기울어짐 느낌이 보고되어 조사 중입니다.
- Clean 004(D0C0653D)는 호스트 테스트와 동일 바이트 재생산만 검증했으며, 이번에 VR 기기로 직접 검증하지 않았습니다. 일반 VR 기능은 Dirty와 같은 공통 코드를 사용합니다.
- 동적 눈 배율과 PC 3D 렌더 비율 조절은 제공하지 않습니다.

### 업데이트 방법

게임을 종료한 뒤 Settings의 새 버전 안내에서 업데이트에 동의하세요. 수동 설치는 사용하는 버전(Clean/Dirty)의 ZIP을 새 폴더에 모두 푼 뒤 포함된 Installer에서 게임 폴더를 선택하세요. 변경되거나 누락된 설치 파일은 Installer의 복구 설치를 사용할 수 있습니다.

**다운로드:** Assets에서 Clean 또는 Dirty ZIP 하나를 선택하세요. Source code ZIP은 설치 패키지가 아닙니다.
