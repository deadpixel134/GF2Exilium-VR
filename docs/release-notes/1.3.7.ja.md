# 1.3.7 — ホーム視点とゲーム更新互換性の修正

[한국어](1.3.7.ko.md) | [English](1.3.7.en.md) | [日本語](1.3.7.ja.md) | [简体中文](1.3.7.zh-CN.md)

最新のSteam・HaoplayでホームVRへの移行とキャラクター背景プレビューの視点を修正しました。固定シーンカメラの代わりに、現在の背景タイムラインが所有する有効なカメラを使用します。Dirtyの接触判定から古いゲーム内部ヘルパー名への依存も除去しました。

Dirtyのホーム視点はSteam・Haoplayの実機テストで正常動作を確認しました。Cleanは共通コードのビルド・パッケージ検証済みですが、個別のHMD検証は未実施です。検証済みローダー構造が同一の場合の名前変更に対応しますが、将来の全更新の互換性は保証しません。CrewdeckやHMD未接続時の安定性の新しい検証結果はありません。

ゲームと設定を終了し、設定の更新機能を使うか、目的のClean/Dirty ZIP全体を新しいフォルダーへ展開してインストーラーを実行してください。既存設定は保持されます。World Dragが無効なら設定で別途有効にしてください。
