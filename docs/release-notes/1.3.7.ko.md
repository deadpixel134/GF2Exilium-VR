# 1.3.7 — 홈 시점 및 최신 업데이트 호환성 수정

[한국어](1.3.7.ko.md) | [English](1.3.7.en.md) | [日本語](1.3.7.ja.md) | [简体中文](1.3.7.zh-CN.md)

최신 Steam·Haoplay에서 홈 VR 진입과 캐릭터 배경 미리보기 시점을 수정했습니다. 현재 배경 타임라인의 활성 카메라를 사용해 잘못된 방향·위치로 진입하던 문제를 해결합니다. Dirty의 캐릭터 터치가 이전 게임 내부 클래스 이름에 의존하던 경로도 제거했습니다.

Dirty 홈 시점 수정은 Steam·Haoplay 실기 테스트에서 정상 확인했습니다. Clean은 같은 공통 코드의 빌드·패키지 검증을 통과했으며 별도 HMD 검증은 하지 않았습니다. 엔진 로더 구조가 동일한 일부 이름 변경에 대응하지만, 모든 향후 업데이트의 호환성을 보장하지 않습니다. Crewdeck 및 HMD 미연결 안정성에 대한 새 검증 결과는 없습니다.

게임과 설정 창을 종료한 뒤 설정의 업데이트 기능을 사용하거나 원하는 Clean/Dirty ZIP 전체를 새 폴더에 풀어 설치 프로그램을 실행하세요. 기존 사용자 설정은 유지합니다. Steam 월드 그랩이 꺼져 있다면 설정에서 별도로 켜 주세요.
