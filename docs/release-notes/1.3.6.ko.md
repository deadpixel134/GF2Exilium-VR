# 1.3.6 — HMD 미연결 실행 보호

[한국어](1.3.6.ko.md) | [English](1.3.6.en.md) | [日本語](1.3.6.ja.md) | [简体中文](1.3.6.zh-CN.md)

HMD가 없는 상태에서 VR 렌더 후킹과 전용 브리지가 먼저 초기화되던 경로를 변경했습니다. 이제 OpenXR에서 HMD를 확인한 뒤 VR 처리를 시작합니다. 실행 중 나중에 HMD를 연결하는 기능과, 활성화 이후의 정리·복구 경로는 유지합니다. v1.3.5의 Crewdeck 정리 수정도 포함합니다.

**Steam 사용자의 비VR 시작 실패·수분 후 크래시 보고에 대응합니다. 정확한 크래시 호출 스택은 제공되지 않았으며, 실제 사용자 환경에서 해결 여부는 아직 확인하지 않았습니다. 초기화 경계 21개, 기존 복구·시계·Crewdeck 검사와 Clean/Dirty 빌드·패키지 검증을 통과했습니다.**

게임과 설정 창을 종료한 뒤 설정 프로그램에서 업데이트하거나 ZIP 전체를 풀어 포함된 설치 프로그램을 실행하세요.
