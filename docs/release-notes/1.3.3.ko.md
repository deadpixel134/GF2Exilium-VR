## 1.3.3 — 한국어

### VR 연결 자동 복구

- 게임 실행 중 VR 세션이 오류로 끊기면 지금까지는 게임을 다시 시작할 때까지 VR이 돌아오지 않았습니다. 이제 끊긴 세션을 정리한 뒤 **10초 간격으로 최대 6번** 새 세션을 만들어 다시 연결합니다. 다시 연결된 세션이 60초 이상 유지되면, 이후의 끊김에서도 다시 6번까지 시도합니다.
- 다시 연결하는 경우: 프레임 제출·이미지·스왑체인 오류, VR 런타임의 세션 손실, 런타임 이벤트 오류.
- 다시 연결하지 않는 경우: SteamVR 등에서 사용자가 앱을 종료한 경우, 게임을 끄는 경우, 게임의 그래픽 장치가 바뀐 경우.
- "처음 활동층에 들어갈 때 VR이 풀리고 메인 메뉴로 나와도 돌아오지 않는다"는 보고를 반영했습니다. 한 번 끊기면 다시 연결하지 않던 동작이 원인으로 확인되어 이를 고쳤습니다. 다만 끊기게 된 계기(PC 사양에 따른 부하 등)는 보고 로그가 없어 확인하지 못했습니다. 여전히 복구되지 않으면 [로그 저장과 전달](https://github.com/deadpixel134/GF2Exilium-VR/blob/main/docs/ko/LOGS.md) 안내에 따라 로그를 보내 주세요.

### 로그 저장과 전달

- Settings **진단** 탭에 **로그 폴더 열기** 버튼을 추가했습니다. 버튼 아래에 저장 위치가 표시되며, 아직 로그가 없으면 켜는 방법을 안내합니다.
- 로그를 켜고 개발자에게 보내는 방법을 [로그 저장과 전달](https://github.com/deadpixel134/GF2Exilium-VR/blob/main/docs/ko/LOGS.md) 문서로 정리했습니다(4개 언어).
- 이번 버전의 로그 파일 이름은 Dirty `GF2VR-DIRTY-133-006.jsonl`, Clean `GF2VR-CLEAN-130-002.jsonl`입니다.

### 기타

- 1.3.2는 내부 후보로 철회되어 공개되지 않았습니다. 1.3.1의 기능(눈 렌더 직전 머리 자세 재획득 등)은 그대로 포함됩니다.
- VR 실행 파일(native 006)은 1.3.1의 004에 위 복구 기능만 더했습니다. Settings와 Installer는 새 VR 실행 파일에 맞춰 다시 빌드했으며 버전은 1.3.3입니다.

### 검증 범위와 알려진 제한

- 복구 동작은 호스트 테스트(재시도 정책 36개 항목)와 기존 네이티브 테스트 24종으로 확인했습니다. 실제 끊김 상황을 재현할 수 없어, VR 기기에서 끊긴 뒤 다시 연결되는 모습은 직접 확인하지 못했습니다.
- 이번 VR 실행 파일(Clean·Dirty 006)은 동일 바이트 재생산과 호스트 테스트로만 검증했으며, 게임과 VR 기기에서 직접 실행해 보지 않았습니다. 복구 코드는 세션이 오류로 끝난 뒤에만 작동하고 평소 동작은 1.3.1과 같도록 만들었습니다.
- Main 화면에서 고개를 돌릴 때의 지연·기울어짐 느낌은 계속 조사 중입니다.

### 업데이트 방법

게임을 종료한 뒤 Settings의 새 버전 안내에서 업데이트에 동의하세요. 수동 설치는 사용하는 버전(Clean/Dirty)의 ZIP을 새 폴더에 모두 푼 뒤 포함된 Installer에서 게임 폴더를 선택하세요. 변경되거나 누락된 설치 파일은 Installer의 복구 설치를 사용할 수 있습니다.

**다운로드:** Assets에서 Clean 또는 Dirty ZIP 하나를 선택하세요. Source code ZIP은 설치 패키지가 아닙니다.
