# 1.3.6 — HMD未接続時の起動を保護

[한국어](1.3.6.ko.md) | [English](1.3.6.en.md) | [日本語](1.3.6.ja.md) | [简体中文](1.3.6.zh-CN.md)

OpenXRがHMDを確認するまで、VRレンダーフックと専用ブリッジの初期化を遅延します。起動後のHMD接続を待機でき、VR有効化後の切断時も既存の解放・復旧処理を維持します。1.3.5のCrewdeck修正も含みます。

**SteamでHMD未接続時に起動失敗または数分後にクラッシュする報告への対応です。クラッシュスタックは未提供で、実機での解決は未確認です。初期化境界21件、既存の復旧・時計・Crewdeck検査とClean/Dirtyビルド・パッケージ検証を通過しました。**

ゲームと設定を終了し、設定の更新機能を使うかZIP全体を展開してインストーラーを実行してください。
