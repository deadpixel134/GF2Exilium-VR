# 1.3.12 — Automatic game-location detection and update summaries

[한국어](1.3.12.ko.md) | [English](1.3.12.en.md) | [日本語](1.3.12.ja.md) | [简体中文](1.3.12.zh-CN.md)

- The installer finds game locations using Windows installation records and Steam libraries. A unique location is filled in; multiple locations can be selected from a list. Manual Browse remains available.
- When the settings GUI discovers a newer version, its existing popup shows up to five release highlights in the current language. Once-per-version notices and the skip option are retained.

Summary display becomes available after installing this GUI, when it later checks a newer version. It cannot add this display retroactively to an already installed older GUI.

These changes affect only the installer and configurator. Clean/Dirty VR DLLs are identical to 1.3.11. Existing user settings and install/update/restore behavior are preserved. Desktop builds, automated checks and location discovery on this PC were verified; no new game/HMD acceptance is implied.
