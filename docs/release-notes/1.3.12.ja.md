# 1.3.12 — ゲームの場所の自動検出と更新概要

[한국어](1.3.12.ko.md) | [English](1.3.12.en.md) | [日本語](1.3.12.ja.md) | [简体中文](1.3.12.zh-CN.md)

- インストーラーがWindowsのインストール情報とSteamライブラリからゲームの場所を探します。1か所なら自動入力、複数なら一覧から選択できます。参照による手動指定も使えます。
- 設定GUIが新しいバージョンを検出すると、現在の言語で最大5件の変更点を既存の通知に表示します。バージョンごとの1回通知と再表示しない設定を維持します。

概要表示はこのGUIをインストールした後、以降の新しいバージョンの確認時に使えます。既存の古いGUIに遡って追加される機能ではありません。

今回の変更はインストーラーと設定GUIのみです。Clean/DirtyのVR DLLは1.3.11と同一です。既存設定とインストール・更新・復元手順を維持します。デスクトップのビルド・自動検査とこのPCの場所検出を確認しました。新しいゲーム・HMD実機検証を意味しません。
