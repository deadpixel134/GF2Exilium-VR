# 1.3.6 — Protect startup without an HMD

[한국어](1.3.6.ko.md) | [English](1.3.6.en.md) | [日本語](1.3.6.ja.md) | [简体中文](1.3.6.zh-CN.md)

Defers VR render hooks and private bridge initialization until OpenXR reports an available HMD system. The game can continue waiting for a later HMD connection. Once VR has activated, existing cleanup and recovery continue through later loss. Includes the v1.3.5 Crewdeck cleanup fix.

**Addresses a Steam report of startup failure or crashes after minutes when no HMD is connected. No crash stack was supplied, and resolution in the affected game environment is not yet confirmed. Validation covers 21 bootstrap boundary checks, existing recovery/clock/Crewdeck tests, and Clean/Dirty builds and packages.**

Close the game and Settings, then use the Settings updater or extract the complete ZIP and run its installer.

Source regression check: in native-source/variants/common, run python test-no-hmd-bootstrap.py --zig PATH_TO_ZIG --output NEW_OUTPUT_DIRECTORY (Windows x64, Zig 0.16.0). Runtime APIs are modeled; no game launch.
