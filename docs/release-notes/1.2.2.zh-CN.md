## 1.2.2 — 简体中文

### 新功能
- Settings新增**PC输出分辨率**预设（原生、3200×1800、2560×1440、1920×1080、1280×720）及应用范围（仅VR期间／始终）。**推荐720p**，代价是PC窗口和辅助面板清晰度降低，从而减轻GPU负担。
- 选择仅VR期间应用时，自动恢复退出VR后在下次启动仍残留的低PC分辨率。
- 更新和移除时保留现有设置文件。

### 更新与设置改进
- 从此版本起，自动更新可适应今后的安装包结构变更。
- 无法自动安装时，仍显示新版本号和手动安装说明；只有点击**打开**才会打开发行页面。支持按版本记忆通知及不再提示。
- 保留有效安装记录时，可重新安装被删除或隔离的模组文件。新Installer的**修复安装**会显示逐文件替换计划，经一次确认后先备份再替换已更改文件。归属不明的文件默认排除。
- 区分产品安装完成与后续处理未完成，可仅重试未完成步骤，无需重新安装产品文件。
- 明确显示保存成功、保存失败、未保存状态及标题*****，关闭未保存更改时提示确认。支持韩语、英语、日语和简体中文。
- 降低日志记录开销。崩溃前约**0.25秒**的日志可能丢失。

### 已知限制
- 动态眼部分辨率缩放和PC三维渲染比例调整因实测无改善，不予提供。
- 此次Clean版未使用VR头显直接测试；其常规VR功能与Dirty使用同一套公共代码。

### 更新方法
- 正常的已有1.2.0或1.2.1安装可在Settings看到新版本提示后确认更新。
- 手动安装：将所用版本（Clean／Dirty）的完整ZIP**全部解压到新文件夹**，在内含的Installer中选择游戏文件夹。自动更新被拒绝时，也可使用新Installer重新安装或修复。
- 安装记录损坏时，请从备份恢复记录和原始文件。不要删除安装记录与恢复文件夹。安装前请关闭游戏。

已撤回的1.2.1的改进内容均包含在1.2.2中。

**下载：** 在Assets中选择一个Clean或Dirty ZIP。Source code ZIP不是安装包。
