## 1.3.1 — 日本語

### VR の姿勢更新

- 目の描画を発行する直前に頭の姿勢を再取得する late re-locate を既定で有効にします。従来はフレーム開始時に読んだ姿勢で目を描いていましたが、メインスレッドの待機後に読み直すため、頭を回したときに映像が頭に追従する遅れがその分だけ減ります。実機測定1回では、送出される姿勢が Main で約12ms、Activity で約27ms 新しくなり、待機が長い重いシーンほど効果が大きくなります。再取得のコストは1フレームあたり0.01ms未満で、失敗した場合は従来の姿勢を使います。フレームレートや実際の表示遅延の改善は測定では確認されていません。
- Settings の **画質・立体感** タブに **目の描画直前に頭の姿勢を再取得** の切り替えを追加しました。チェックを外して保存すると `performance.json` に `"pose": { "lateRelocate": false }` が書き込まれ、ゲームを再起動すると 1.2.2 以前の動作になります。キーがない場合は有効です。

### ログ・インストールの改善

- ログの破棄数・書き込み失敗数が変化した場合、要約を最短 1 秒間隔で記録します。変化がなくても 10 秒ごとに記録します。書き込みエラー後も次のログの処理を継続できます。クラッシュや突然の終了時には直前の約 0.25 秒分が失われる場合があります。
- インストール・更新・修復インストールでは内容が同じファイルを書き直さず、更新日時を維持します。インストール記録・バックアップ・復元・設定の保持・整合性検査は維持されます。単独公開しなかった 1.2.3 の改善を含みます。
- Settings と Installer を新しい VR 実行ファイルに合わせて更新しました。Settings・パッケージ・インストール記録のバージョンは 1.3.1 です。
- 1.3.0 は切り替え項目のない状態で一時公開した後に取り下げました。その内容はすべて 1.3.1 に含まれます。1.3.0 を導入した場合は Settings の案内から 1.3.1 に更新してください。

### 既知の制限

- Main で頭を左右に動かす際の遅れ・傾きの感覚が報告されており、調査中です。
- Clean 004（D0C0653D）はホストテストと同一バイトの再生成のみを検証しました。今回 VR 機器での直接検証は行っていません。一般的な VR 機能は Dirty と共通のコードを使用します。
- 動的な目の解像度調整と PC 3D 描画倍率の調整は提供しません。

### 更新方法

ゲームを終了して Settings の更新案内に同意してください。手動では Clean/Dirty の該当 ZIP を新しいフォルダーにすべて展開し、同梱の Installer でゲームフォルダーを選択します。変更・欠落したインストールファイルには修復インストールを利用できます。

**ダウンロード:** Assets から Clean または Dirty の ZIP を 1 つ選択してください。Source code ZIP はインストール用ではありません。
