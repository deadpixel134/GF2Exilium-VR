## 1.3.1 — 简体中文

### VR 姿态更新

- 默认启用 late re-locate：在提交眼部渲染任务前再次读取头部姿态。以前使用帧开始时读取的姿态绘制双眼，现在在主线程等待之后重新读取，因此转头时画面跟随头部的延迟会相应减少。一次实机测量中，提交的姿态在 Main 约新 12ms，在 Activity 约新 27ms；场景越重、等待越长，效果越明显。重新读取的开销每帧低于 0.01ms，失败时使用原有姿态。帧率或实际显示延迟的改善未经测量确认。
- Settings 的 **画质·立体感** 标签页新增 **眼睛渲染前重新读取头部姿态** 开关。取消勾选并保存后，`performance.json` 中会写入 `"pose": { "lateRelocate": false }`，重启游戏后恢复 1.2.2 及更早版本的行为。未提供此键时默认开启。

### 日志与安装改进

- 丢弃计数或写入失败计数变化时，日志摘要最短每秒记录一次；没有变化时也每十秒记录一次。写入错误后，后续日志批次可继续处理。崩溃或突然退出时，可能丢失最后约 0.25 秒的日志。
- 安装、更新和修复安装跳过内容相同的文件写入，并保留其修改时间。安装记录、备份、还原、设置保留和完整性检查保持不变。此项包含未单独发布的 1.2.3 安装改进。
- Settings 和 Installer 已更新以匹配新的 VR 运行文件。Settings、安装包与安装记录的版本均为 1.3.1。
- 1.3.0 曾在没有该开关的情况下短暂发布并随后撤回，其全部内容均包含在 1.3.1 中。已安装 1.3.0 的用户请在 Settings 的提示中更新到 1.3.1。

### 已知限制

- 已收到在 Main 左右转头时有延迟或倾斜感的报告，正在调查。
- Clean 004（D0C0653D）仅完成主机测试及逐字节一致的重现验证，本次未使用 VR 设备直接验证。其通用 VR 功能与 Dirty 使用相同的公共代码。
- 不提供动态眼部分辨率缩放和 PC 3D 渲染比例调整。

### 更新方法

关闭游戏后，在 Settings 的新版本提示中同意更新。手动安装时，请将对应版本（Clean/Dirty）的 ZIP 完整解压到新文件夹，再使用其中的 Installer 选择游戏目录。安装文件被修改或缺失时，可以使用修复安装。

**下载：** 从 Assets 中选择一个 Clean 或 Dirty ZIP。Source code ZIP 不是安装包。
