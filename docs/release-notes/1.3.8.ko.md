# 1.3.8 — 게임 업데이트 내성 개선

[한국어](1.3.8.ko.md) | [English](1.3.8.en.md) | [日本語](1.3.8.ja.md) | [简体中文](1.3.8.zh-CN.md)

홈 장면과 카메라 식별에서 난독화된 클래스·필드 이름 의존성을 줄였습니다. 고유한 메타데이터 구조, 현재 장면과 레지스트리의 일치, 장면이 소유한 카메라 관계를 검증합니다. 모호하거나 변경된 구조는 추측해서 선택하지 않습니다.

배포하는 Dirty DLL은 Steam·Haoplay에서 사용자가 실기 검증한 파일과 동일합니다. 홈 VR 및 요청된 캐릭터 배경 전환이 정상 확인됐습니다. Clean은 같은 공통 코드의 빌드·패키지 검증을 통과했으며 별도 HMD 검증은 하지 않았습니다. 기본 카메라의 소유 관계 탐색은 확인했지만, 별도의 기본 카메라 fallback VR 화면까지 검증한 것은 아닙니다. 모든 향후 게임 업데이트의 호환성을 보장하지 않습니다.

게임과 설정 창을 종료한 뒤 설정의 업데이트 기능을 사용하거나 원하는 Clean/Dirty ZIP 전체를 새 폴더에 풀어 설치 프로그램을 실행하세요. 기존 사용자 설정을 유지합니다.
