## 1.3.1 — English

### VR pose refresh

- Late re-locate is enabled by default: the mod reads the head pose again immediately before issuing the eye render. Previously the eyes were drawn with the pose read at the start of the frame; reading it again after the main-thread wait reduces, by that amount, how far the image lags behind your head when you turn it. In one HMD measurement the submitted pose was about 12 ms (Main) and 27 ms (Activity) more recent, and the effect grows in heavier scenes where the wait is longer. The re-read costs under 0.01 ms per frame, and if it fails the existing pose is used. No improvement in frame rate or actual display latency has been confirmed by measurement.
- Settings now has a **Re-read head pose right before eye rendering** toggle on the **Image quality / stereo** tab. Unchecking it and saving writes `"pose": { "lateRelocate": false }` to `performance.json`; after restarting the game, the mod behaves as in 1.2.2 and earlier. An absent key means enabled.

### Logging and installation

- Log summaries are written when drop or write-failure counters change, at most once per second, and every ten seconds when unchanged. A write error no longer prevents the next batch from progressing. A crash or abrupt exit can lose approximately the last 0.25 seconds of logs.
- Install, update, and Repair skip rewriting files with identical contents, preserving their modification times. Installation records, backups, restoration, settings preservation, and integrity checks remain in place. This includes the installation improvement from the unpublished 1.2.3 package.
- Settings and Installer have been updated to match the new VR runtime. Settings, the package, and the installation record use version 1.3.1.
- 1.3.0 was briefly published without the toggle and then withdrawn; everything from it is included in 1.3.1. If you installed 1.3.0, accept the 1.3.1 prompt in Settings.

### Known limitations

- A feeling of lag or tilt while turning the head on Main has been reported and is under investigation.
- Clean 004 (D0C0653D) has only host-test and byte-for-byte reproduction verification. It has not been tested directly with a VR headset for this release. Its general VR features share the same common code as Dirty.
- Dynamic eye scaling and PC 3D render scaling are not offered.

### Updating

Close the game and accept the new-version prompt in Settings. For manual installation, extract the entire ZIP for your version (Clean/Dirty) into a new folder, then select the game folder in the included Installer. Use Repair for modified or missing installed files.

**Download:** Choose one Clean or Dirty ZIP from Assets. The Source code ZIP is not an installation package.
