# 1.3.4 — ゲーム更新への互換性対応

[한국어](1.3.4.ko.md) | [English](1.3.4.en.md) | [日本語](1.3.4.ja.md) | [简体中文](1.3.4.zh-CN.md)

Haoplay 3.0.5388およびSteam 3.0.5400で変更された内部API名に対応しました。従来の接続情報ではVR初期化に必要なAPIを取得できなかった問題を修正しています。

両プラットフォームで同じClean・Dirtyパッケージを使用します。既存のVR機能と1.3.3のセッション再接続機能を維持し、ユーザー設定を保持します。

**実際のゲーム・HMDでの動作確認は行っていません。両ゲームDLLの静的解析で接続情報を確認し、API検索、フックの安全性、ビルド、パッケージの自動検証を実施しました。実行時の互換性問題が残っている可能性があります。**

ゲームと設定画面を終了し、設定画面の更新機能を利用するか、Clean/Dirty ZIP全体を展開して同梱のインストーラーを実行してください。
