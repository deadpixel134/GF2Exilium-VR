# 1.3.4 — 游戏更新兼容性修复

[한국어](1.3.4.ko.md) | [English](1.3.4.en.md) | [日本語](1.3.4.ja.md) | [简体中文](1.3.4.zh-CN.md)

适配Haoplay 3.0.5388和Steam 3.0.5400更新后的内部API名称。游戏更新后，旧映射无法找到VR初始化所需的API，此版本修复了该映射问题。

两个平台使用相同的Clean/Dirty安装包。保留现有VR功能和1.3.3的会话重连功能，并保留用户设置。

**尚未进行实际游戏或HMD运行验证。已通过静态分析核对两个版本的游戏DLL，并完成API查找、Hook安全性、构建和安装包自动检查。仍可能存在其他运行时兼容性问题。**

关闭游戏和设置窗口后，使用设置程序的更新功能，或完整解压Clean/Dirty ZIP并运行其中的安装程序。
