# 1.3.12 — 설치 경로 자동 탐색과 업데이트 요약

[한국어](1.3.12.ko.md) | [English](1.3.12.en.md) | [日本語](1.3.12.ja.md) | [简体中文](1.3.12.zh-CN.md)

- 인스톨러가 Windows 설치 정보와 Steam 라이브러리에서 게임 경로를 자동으로 찾습니다. 한 곳이면 채우고 여러 곳이면 목록에서 선택할 수 있습니다. 직접 찾아보기도 유지합니다.
- 설정 GUI가 새 버전을 발견하면 릴리스의 주요 변경 사항을 현재 언어로 최대 5개 표시합니다. 버전별 1회 알림과 다시 보지 않기를 유지합니다.

업데이트 요약 표시는 이 버전의 GUI를 설치한 뒤 이후 새 버전을 확인할 때 적용됩니다. 기존 GUI에 표시 내용을 소급 추가하는 기능은 아닙니다.

이번 변경은 설치기와 설정 GUI에 한정됩니다. Clean·Dirty의 VR DLL은 1.3.11과 동일합니다. 기존 사용자 설정과 설치·업데이트·복원 절차를 유지합니다. 데스크톱 빌드·자동 검사와 이 PC의 경로 탐색을 확인했으며, 새 게임/HMD 실기 검증을 의미하지 않습니다.
