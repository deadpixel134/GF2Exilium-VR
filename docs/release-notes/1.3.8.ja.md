# 1.3.8 — ゲーム更新への耐性を改善

[한국어](1.3.8.ko.md) | [English](1.3.8.en.md) | [日本語](1.3.8.ja.md) | [简体中文](1.3.8.zh-CN.md)

ホームのシーン・カメラ識別で難読化されたクラス名・フィールド名への依存を減らしました。一意のメタデータ構造、現在のシーンとレジストリの同一性、シーンが所有するカメラの関係を検証します。曖昧または変更された構造を推測で選択しません。

配布するDirty DLLはSteam・Haoplayでユーザーが実機検証したファイルと同一です。ホームVRと指定されたキャラクター背景の切り替えは正常でした。Cleanは共通コードのビルド・パッケージ検証済みですが、個別のHMD検証は未実施です。基本カメラの所有関係は確認しましたが、別途フォールバックカメラのVR出力まで検証したものではありません。将来のすべてのゲーム更新への互換性は保証しません。

ゲームと設定を終了し、設定の更新機能を使うか、目的のClean/Dirty ZIP全体を新しいフォルダーへ展開してインストーラーを実行してください。既存設定は保持されます。
