# GF2VR 1.2.1

## New features

- Settings now offers **PC output resolution** presets and a scope of **VR only / Always**; we recommend 720p to reduce GPU load, at the cost of a less sharp PC window and auxiliary panel.
- If a low resolution remains on the next launch after leaving VR, the desktop resolution is restored automatically.
- Updates preserve your existing settings files.

## Improvements

- Logging now batches entries and writes them periodically. A crash may lose approximately **0.25 seconds** of recent logs.
- Update failures explain the cause, affected file and next action in **Korean, English and Japanese**.

## Known limitations

- Dynamic eye scaling and PC 3D render scaling are not offered because they did not improve performance.
- The Clean version was not tested directly with a VR headset for this release; its VR features share the same common code as Dirty, apart from character-contact deformation.

## How to update

- **An intact 1.2.0 installation:** Open Settings, then confirm the update notification to install automatically.
- **Manual update:** Extract the entire ZIP for your version (Clean/Dirty) into a new folder, then select your game folder in the included Installer.
- If installed files have been changed or deleted, the Installer will refuse installation. Restore a backup of the same version and try again. A repair installation option is planned for the next version.

[Download the latest Clean/Dirty packages](https://github.com/deadpixel134/GF2Exilium-VR/releases/latest)
