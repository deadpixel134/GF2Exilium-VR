# GF2VR 1.2.1 — draft release notes

Draft release notes. The source PR and unpublished draft are authorized; stable publication awaits a separate user instruction.

- Settings adds PC output presets and VR-only/always scope. Native remains the default.720p is recommended to reduce GPU load, with reduced PC-window and auxiliary-panel sharpness.
- PC resolution is applied for immersive mode and the captured startup size is restored on exit. If the fixed size remains at the next startup after an immersive exit, desktop resolution is restored.
- Installer creates NATIVE/IMMERSIVE_ONLY performance.json only when absent. Existing bytes, unknown keys and dynamicEyeScale objects are preserved.
- Logs use one handle, a ring buffer and periodic asynchronous flushing. A crash can lose up to250ms of recent logs.
- ko/en/ja refusal messages provide the condition, affected file and next action. Settings exposes detailed guidance from its status area.

**Clean flavor has not been HMD-tested; it shares the common code.** Clean has host validation only. Dirty003's Haoplay Main/Activity/F8/resolution regression acceptance does not establish Clean or all Steam-scene HMD acceptance.

Fixed eye scaling is retained. Dynamic eye scaling is disabled after no measured throughput gain and unresolved transition/navigation issues. PC3D renderScale is unsupported because it showed no throughput gain.

Normal managed1.2.0 updates retain the legacy wire format. Actual official1.2.0 binaries executed staging/handoff, with new-helper installation and exact rollback in isolation. GitHub download through the oldGUI is NOT_RUN before publication; a post-publication smoke is mandatory. Manual update: extract the entire matching Clean/Dirty ZIP into a fresh folder and use its Installer1.2.1 against the existing game folder.

Missing or modified owned files remain refused. Restore a verified backup of the same installed version before retrying. Forced Repair is not provided. The proposed missing-file-only restoration relaxation is also unimplemented pending separate approval.
