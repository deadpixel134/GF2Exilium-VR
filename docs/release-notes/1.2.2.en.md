## 1.2.2 — English

### New features
- Settings now offers **PC output resolution** presets (Native, 3200×1800, 2560×1440, 1920×1080 and 1280×720), applied only in VR or throughout the session. **720p is recommended** to reduce GPU load at the cost of a less sharp PC window and auxiliary panel.
- With VR-only output selected, automatically recovers a reduced PC resolution left behind when starting the game after exiting VR.
- Preserves existing settings files during updates and removal.

### Update and settings improvements
- Starting with this version, automatic updates can follow future package-layout changes.
- A newer version and manual-install guidance remain visible when automatic installation is unavailable. The release page opens only when you select **Open**. Notifications remember each version and support skipping it.
- Missing or quarantined mod files can be reinstalled when a valid installation record remains. The new Installer's **Repair** shows a per-file replacement plan and backs up changed files before replacing them after one confirmation. Files with unknown ownership are excluded by default.
- Distinguishes completed product installation from unfinished final steps; retry those steps without reinstalling product files.
- Clearly displays saved, failed-save and unsaved states, an asterisk (`*`) in the window title, and a warning before closing with unsaved changes. Korean, English, Japanese and Simplified Chinese are supported.
- Reduces logging overhead. About **0.25 seconds** of logs immediately before a crash may be lost.

### Known limitations
- Dynamic eye scaling and PC 3D render-scale controls are not offered because measurements showed no improvement.
- Clean has not been tested directly with a VR headset for this release. Its ordinary VR features share the same common code as Dirty.

### Updating
- For a normal existing 1.2.0 or 1.2.1 installation, confirm the newer-version prompt in Settings to update.
- Manual installation: extract the entire ZIP for your variant (Clean/Dirty) into a **new folder**, then select the game folder in its Installer. If automatic updating is refused, use the new Installer to reinstall or repair.
- If the installation record is damaged, restore the record and original files from backup. Keep installation records and recovery folders. Close the game before installation.

The withdrawn 1.2.1 release's improvements are included in 1.2.2.

**Download:** choose one Clean or Dirty ZIP under Assets. The Source code ZIP is not an installer package.
