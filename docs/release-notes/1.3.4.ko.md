# 1.3.4 — 게임 업데이트 호환성 수정

[한국어](1.3.4.ko.md) | [English](1.3.4.en.md) | [日本語](1.3.4.ja.md) | [简体中文](1.3.4.zh-CN.md)

Haoplay 3.0.5388 및 Steam 3.0.5400 업데이트에서 변경된 내부 API 이름에 대응합니다. 이전 연결 정보로는 VR 초기화에 필요한 API를 찾을 수 없던 문제를 수정했습니다.

두 플랫폼에서 같은 Clean·Dirty 패키지를 사용합니다. 기존 VR 기능과 1.3.3의 세션 재연결 기능을 유지하며, 사용자 설정을 변경하지 않습니다.

**실제 게임/HMD 실행 검증은 수행하지 않았습니다. 두 버전의 DLL을 정적으로 분석해 연결 정보를 확인했고, API 조회·훅 안전성·빌드·패키지 자동 검증을 수행했습니다. 게임 실행 중의 추가 호환성 문제는 남아 있을 수 있습니다.**

게임과 설정 창을 종료한 뒤 설정 프로그램의 업데이트 기능을 이용하거나, 원하는 Clean/Dirty ZIP 전체를 풀어 포함된 설치 프로그램을 실행하세요.
