## 1.2.2 — 日本語

### 新機能
- Settingsに**PC出力解像度**のプリセット（元の解像度、3200×1800、2560×1440、1920×1080、1280×720）と適用範囲（VR中のみ／常時）を追加しました。**720pを推奨**します。GPU負荷が減る代わりに、PCウィンドウと補助パネルの鮮明さが下がります。
- VR中のみの適用を選んだ場合、VR終了後の次回起動でもPC解像度が低いまま残る問題を自動復旧します。
- 更新・削除時に既存の設定ファイルを保持します。

### 更新・設定の改善
- このバージョンから、自動更新が今後のパッケージ構成の変更に対応できるようになりました。
- 自動適用ができない場合も新バージョンと手動インストール案内を表示します。リリースページは**開く**を押したときだけ開きます。バージョンごとの通知と「再表示しない」に対応します。
- 有効なインストール記録が残っていれば、削除・隔離されたMODファイルを再インストールできます。新Installerの**修復インストール**では、ファイルごとの置換計画を一度確認・同意した後、変更ファイルをバックアップして置き換えます。所有元不明のファイルは初期状態で除外します。
- 製品のインストール完了と未完了の後処理を区別し、製品ファイルを再インストールせずに後処理だけ再試行できます。
- 保存成功・失敗・未保存の状態、タイトルの*****、未保存のまま閉じる際の警告を追加しました。韓国語・英語・日本語・簡体字中国語に対応します。
- ログ記録の負荷を軽減しました。クラッシュ直前の約**0.25秒**のログが失われる場合があります。

### 既知の制限
- 動的な目の解像度倍率とPCの3Dレンダー倍率調整は、測定で改善が見られなかったため提供しません。
- 今回のClean版はVR機器で直接検証していません。通常のVR機能はDirtyと同じ共通コードを使っています。

### 更新方法
- 1.2.0または1.2.1の正常な既存インストールでは、Settingsの新バージョン案内を確認して更新に同意してください。
- 手動の場合は、使用するClean／Dirtyの完全版ZIPを**新しいフォルダーにすべて展開**し、同梱Installerでゲームフォルダーを選択してください。自動更新が拒否されても、新Installerで再インストールや修復を行えます。
- インストール記録が破損している場合は、記録と元のファイルをバックアップから復元してください。記録と復元フォルダーは削除しないでください。インストール前にゲームを終了してください。

取り下げた1.2.1の改善内容は1.2.2に含まれます。

**ダウンロード：** AssetsからCleanまたはDirtyのZIPを一つ選んでください。Source code ZIPはインストール用ではありません。
