# GF2VR 1.2.1

## 새 기능

- Settings에 **PC 출력 해상도** 프리셋과 적용 범위(**VR 중에만 / 항상**)를 추가했으며, GPU 부담을 줄이려면 720p를 권장하지만 PC 창과 보조 패널은 덜 선명해집니다.
- VR 종료 후 다음 실행에도 낮은 해상도가 남아 있으면 데스크톱 해상도로 자동 복구합니다.
- 업데이트할 때 기존 설정 파일을 보존합니다.

## 개선

- 로그를 모아 주기적으로 기록하도록 개선했습니다. 크래시 직전 약 **0.25초** 분량의 로그는 유실될 수 있습니다.
- 업데이트 실패 시 원인, 문제 파일, 다음 행동을 **한국어·영어·일본어**로 안내합니다.

## 알려진 제한

- 동적 눈 배율과 PC 3D 렌더 비율 조절은 성능 개선 효과가 없어 제공하지 않습니다.
- Clean 버전은 이번에 VR 기기로 직접 검증하지 않았으며, 캐릭터 접촉 변형을 제외한 VR 기능은 Dirty와 같은 공통 코드를 사용합니다.

## 업데이트 방법

- **정상 설치된 1.2.0:** Settings를 열면 업데이트가 안내되며, 확인하면 자동으로 설치됩니다.
- **수동 업데이트:** 사용 중인 버전(Clean/Dirty)의 ZIP을 새 폴더에 모두 풀고, 포함된 Installer에서 게임 폴더를 선택하세요.
- 설치 파일이 변경되거나 삭제된 경우 Installer가 설치를 거절합니다. 같은 버전의 백업을 복원한 뒤 다시 시도하세요. 복구 설치는 다음 버전에서 제공할 예정입니다.

[최신 Clean/Dirty 패키지 다운로드](https://github.com/deadpixel134/GF2Exilium-VR/releases/latest)
