## 1.2.2 — 한국어

### 새 기능
- Settings에 **PC 출력 해상도** 프리셋(원본, 3200×1800, 2560×1440, 1920×1080, 1280×720)과 적용 범위(VR 중에만/항상)를 추가했습니다. **720p를 권장**하며, GPU 부담이 줄어드는 대신 PC 창과 보조 패널이 덜 선명해집니다.
- VR 중에만 적용하도록 설정했을 때, VR 종료 후 다음 실행에서도 낮은 PC 해상도가 남는 경우를 자동으로 복구합니다.
- 업데이트와 제거 시 기존 설정 파일을 보존합니다.

### 업데이트·설정 개선
- 이 버전부터 자동 업데이트가 향후 패키지 구성 변경을 따라갈 수 있도록 개선했습니다.
- 자동 적용이 불가능해도 새 버전 번호와 수동 설치 안내를 표시하며, 릴리스 페이지는 **열기**를 눌러야 열립니다. 버전별 알림과 다시 보지 않기를 지원합니다.
- 유효한 설치 기록이 남아 있으면 삭제·격리된 모드 파일을 재설치할 수 있습니다. 변경된 파일은 새 Installer의 **복구 설치**에서 파일별 교체 계획을 확인하고 한 번 동의한 뒤 백업·교체할 수 있습니다. 소유가 확인되지 않은 파일은 기본 제외됩니다.
- 제품 설치가 끝난 뒤의 후처리 실패를 따로 표시하고, 파일 재설치 없이 남은 단계만 재시도할 수 있습니다.
- 저장 성공·실패·미저장 상태와 창 제목의 별표(`*`) 표시, 미저장 상태에서 닫기 경고를 추가했습니다. 한국어·영어·일본어·简体中文을 지원합니다.
- 로그 기록 부담을 줄였습니다. 크래시 직전 약 **0.25초**의 로그는 남지 않을 수 있습니다.

### 알려진 제한
- 동적 눈 배율과 PC 3D 렌더 비율 조절은 측정에서 개선 효과가 없어 제공하지 않습니다.
- Clean 버전은 이번에 VR 기기로 직접 시험하지 않았습니다. 일반 VR 기능은 Dirty와 같은 공통 코드를 사용합니다.

### 업데이트 방법
- 기존 1.2.0 또는 1.2.1의 정상 설치에서는 Settings의 새 버전 안내를 확인하고 업데이트에 동의하세요.
- 수동 설치: 사용하는 버전(Clean/Dirty)의 전체 ZIP을 **새 폴더에 모두 풀고**, 포함된 Installer에서 게임 폴더를 선택하세요. 자동 업데이트가 거절된 경우에도 새 Installer에서 재설치·복구를 진행할 수 있습니다.
- 설치 기록이 손상됐다면 백업에서 기록과 원본 파일을 복원하세요. 기존 설치 기록과 복구 폴더는 삭제하지 마세요. 게임은 설치 전에 종료해야 합니다.

1.2.1 배포는 철회했으며, 해당 개선 사항은 1.2.2에 포함했습니다.

**다운로드:** 아래 Assets에서 Clean 또는 Dirty ZIP 하나를 받으세요. Source code ZIP은 설치 파일이 아닙니다.
