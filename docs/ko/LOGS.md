# 로그 저장과 전달

[한국어](../ko/LOGS.md) | [English](../en/LOGS.md) | [日本語](../ja/LOGS.md) | [简体中文](../zh-CN/LOGS.md)

[처음으로](../../README.md)

문제를 알릴 때 VR 모드의 진단 로그를 함께 보내 주시면 원인을 찾는 데 큰 도움이 됩니다. 로그 기록은 기본으로 꺼져 있으므로 아래 순서대로 켜고, 문제를 다시 겪은 뒤 파일을 보내 주세요.

## 1. 로그 저장 켜기

1. 게임을 종료합니다.
2. 설정 프로그램을 엽니다. 인스톨러의 **설정 열기**를 누르거나 게임 폴더의 `vrmod/bin/GF2VR.Configurator/GF2VR.Configurator.exe`를 실행합니다.
3. **진단** 탭에서 **로그 자동 기록**을 체크하고 **저장**을 누릅니다.
4. 게임을 다시 실행합니다. 저장한 설정은 게임을 다시 시작해야 적용됩니다.

## 2. 문제 다시 겪기

- 문제가 생긴 화면까지 가서 같은 증상을 한 번 재현한 뒤 게임을 종료하세요.
- 로그는 게임을 실행할 때마다 같은 파일 뒤에 이어서 기록되며, 한 번 실행에 100MB를 넘을 수 있습니다. 이번 문제만 담으려면 게임을 실행하기 전에 기존 로그 파일을 다른 폴더로 옮겨 두세요.
- 게임이 갑자기 꺼지면 마지막 약 0.25초 분량은 기록되지 않을 수 있습니다.

## 3. 로그 폴더 열기

- **1.3.3부터:** 설정 프로그램의 **진단** 탭에서 **로그 폴더 열기**를 누르면 탐색기에서 로그 폴더가 열립니다. 버튼 아래에 저장 위치가 표시됩니다. 아직 로그가 만들어지지 않았다면 안내 메시지가 표시됩니다.
- **직접 열기:** 설정 프로그램 맨 위 **게임 폴더**에 표시된 경로 아래의 `vrmod\logs\bootstrap` 폴더입니다.
  - Steam판처럼 `GF2_Exilium.exe`가 게임 폴더에 바로 있으면 `<게임 폴더>\vrmod\logs\bootstrap`입니다.
  - Haoplay판처럼 `GF2_Exilium.exe`가 `GF2 Game` 폴더 안에 있으면 `GF2 Game`의 상위 폴더 아래 `vrmod\logs\bootstrap`입니다.

## 4. 보낼 파일 고르기

- `GF2VR-CLEAN-` 또는 `GF2VR-DIRTY-`로 시작하는 `.jsonl` 파일 중 **수정한 날짜가 가장 최근인 파일**을 고르세요. 이름이 같은 `.inventory.jsonl` 파일이 있으면 함께 보내 주세요.
- 파일 이름은 버전에 따라 달라집니다. 예를 들어 1.3.3에서는 Dirty가 `GF2VR-DIRTY-133-006.jsonl`, Clean이 `GF2VR-CLEAN-130-002.jsonl`이고, 1.3.1의 Dirty는 `GF2VR-DIRTY-130-004.jsonl`입니다.
- 고른 파일을 ZIP으로 압축하세요. Windows 11은 마우스 오른쪽 버튼 → **압축 대상** → **ZIP 파일**, Windows 10은 마우스 오른쪽 버튼 → **보내기** → **압축(ZIP) 폴더**입니다. 텍스트 로그라서 크게 줄어듭니다(예: 약 100MB → 약 5MB).

## 5. 개발자에게 보내기

- [GitHub Issues](https://github.com/deadpixel134/GF2Exilium-VR/issues/new)에서 새 이슈를 만들고 ZIP 파일을 입력창에 끌어다 놓아 첨부하세요. GitHub 첨부 파일은 25MB까지 올릴 수 있습니다.
- 또는 [아카라이브 가상현실 채널](https://arca.live/b/vrshits)에 글을 올려 주세요.
- 파일이 너무 크면 Google Drive 같은 클라우드 저장소에 올리고 공유 링크를 함께 적어 주세요.
- 다음 내용도 함께 적어 주세요.
  - 설치 종류(Clean/Dirty)와 버전, Haoplay/Steam
  - 헤드셋과 연결 방식(예: Quest 3 + Virtual Desktop)
  - 문제가 생긴 화면, 재현 순서, 화면에 나온 오류 메시지
  - 문제가 생긴 대략적인 시각

## 6. 공유하기 전에

- GitHub 이슈와 아카라이브 글은 누구나 볼 수 있습니다.
- 로그는 VR 모드의 동작 기록(이벤트·상태·성능 수치)입니다. 로그 파일만 보내고, 게임 원본 파일, 계정·인증 정보, 요청받지 않은 다른 파일은 보내지 마세요.

## 7. 다 쓴 뒤 끄기

문제 확인이 끝나면 **진단** 탭에서 **로그 자동 기록** 체크를 해제하고 저장하세요. 켜 두면 로그 파일이 계속 커집니다. 이미 보낸 로그 파일은 지워도 됩니다.
