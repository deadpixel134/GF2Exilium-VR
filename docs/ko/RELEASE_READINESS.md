# 다운로드와 지원 안내

## 지금 내려받아 설치할 수 있나요?

현재 이 저장소에는 **최신 전체 VR 모드 설치 파일을 배포하지 않습니다.** 설정 프로그램과 인스톨러의 소스 및 사용 안내를 제공하고 있으며, 저장소는 비공개입니다.

GitHub의 Code 메뉴에서 내려받는 ZIP은 설치 파일이 아닙니다. 그대로 게임 폴더에 넣거나 실행 파일 일부를 따로 복사해 사용하지 마세요.

게임에 맞는 설치 파일을 별도로 전달받은 경우에는 [설치 안내](INSTALLATION.md)에 따라 진행할 수 있습니다. 일부 묶음은 설정 프로그램만 설치할 수 있으므로 인스톨러 화면의 설명을 확인하세요.

## 어떤 환경에서 사용할 수 있나요?

Windows PC에서 실행하는 GF2 Exilium을 대상으로 합니다. 게임을 정식으로 설치하고, 헤드셋과 컨트롤러를 사용할 수 있는 VR 실행 환경이 필요합니다. 게임과 SteamVR는 사용자가 직접 실행합니다.

모든 헤드셋·연결 방식·게임 장면에서 확인된 것은 아닙니다. 최신 기능과 다른 설치 환경에서의 실제 VR 확인이 남아 있습니다. 자세한 내용은 [확인된 동작과 제한 사항](VERIFICATION.md)을 참고하세요.

## 다른 사용자도 자동 업데이트할 수 있나요?

현재는 비공개 저장소 소유자 본인의 사용을 전제로 합니다. 다른 사용자에게 파일을 전달하는 방법과 업데이트 이용 조건은 아직 정하지 않았습니다. 저장소에 접근할 수 있다고 자동 업데이트가 반드시 제공되는 것은 아닙니다.

설치 파일이 없는 경우 지금은 이 문서에서 기능과 사용 방법을 확인하는 용도로 이용해 주세요.

## 이용 조건과 문의

프로젝트 소스의 배포 라이선스는 아직 정하지 않았습니다. 원본 게임은 포함하지 않으며, 게임과 관련된 권리는 각 권리자에게 있습니다.

사용 중 문제가 생기면 먼저 [문제 해결 안내](TROUBLESHOOTING.md)를 확인하고 오류 메시지와 발생 순서를 정리해 주세요.
