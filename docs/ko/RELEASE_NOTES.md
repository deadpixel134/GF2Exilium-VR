# 최근 변경 사항

[한국어](../ko/RELEASE_NOTES.md) | [English](../en/RELEASE_NOTES.md) | [日本語](../ja/RELEASE_NOTES.md) | [简体中文](../zh-CN/RELEASE_NOTES.md)

## 1.0.2 · 2026년 10월 16일

- 패키지 경로 선택란을 없앴습니다. ZIP을 전부 푼 뒤 인스톨러에서 게임 폴더만 선택하세요. 설치 파일은 인스톨러 옆에서 자동으로 찾습니다.
- 설치 기록이 없어도 현재 패키지와 정확히 같은 파일은 백업 후 설치할 수 있습니다. 제거할 때는 먼저 있던 파일을 복원합니다.
- 수정된 파일과 출처가 다른 DLL은 보존하며, 설치 기록 누락과 파일 변경을 구분해 조치 방법을 안내합니다.
- VR 렌더링과 헤드셋 동작은 변경하지 않았습니다. 이번 변경은 로컬 자동·GUI 검증을 거쳤으며 제보자 PC나 게임/HMD 실기 확인을 새로 한 것은 아닙니다.

기존 버전 사용자는 1.0.2 ZIP을 새 폴더에 전부 풀고 포함된 인스톨러에서 기존 게임 폴더를 선택하세요. 설정과 정상 설치 기록을 유지합니다.

## 1.0.1 · 2026년 10월 16일

- 폴더 이름이나 중첩 구조가 달라도 `GF2_Exilium.exe`를 찾도록 설치 경로 검색을 개선했습니다. 실행 파일이 있는 폴더나 이를 포함하는 설치 폴더를 선택하면 됩니다. 여러 개를 찾으면 더 가까운 폴더를 선택하세요.
- 원본 게임의 SHA-256·파일 크기·캐시 차이만으로 설치를 막지 않습니다. **2.0.3936**은 실기 확인 기준으로 유지하며 다른 버전의 VR 동작을 보장하지는 않습니다.
- 기본 `GF2 Game` 구조는 기존 상위 폴더의 `vrmod`를 유지하고, 다른 구조는 실행 파일 폴더의 `vrmod`를 사용합니다. `version.dll`은 실행 파일 옆에 설치됩니다.
- 제품 파일 해시·소유권·실행 중인 게임 차단·이전 버전 복원·중단 복구 검사는 유지합니다.

1.0.0에서 업데이트하려면 1.0.1 ZIP을 직접 내려받아 포함된 새 인스톨러를 사용하세요. 이전 설정 프로그램이 새 패키지를 거절해도 이 경로로 설정과 설치 기록을 유지할 수 있습니다.

로컬 설치·업데이트·복구와 경로 검증을 통과했습니다. 변경 후 보고자 PC나 실제 게임/HMD 실행은 새로 기록하지 않았습니다. [확인 범위](VERIFICATION.md)와 [설치 안내](INSTALLATION.md)를 참고하세요.

## 1.0.0 · 2026년 10월 15일

현재 구현의 실기 테스트 완료 확인을 기준으로 첫 정식 버전을 배포합니다. [설치 ZIP과 다운로드 안내](RELEASE_READINESS.md)에서 시작하세요.

### VR 화면과 조작

- 지원되는 3D 장면의 입체 화면, 머리 추적, 정면·보조 패널과 컨트롤러 조작을 포함합니다.
- 월드 크기에 맞춘 입체감·이동 속도 연동, 왼쪽 스틱 클릭 시점 복귀, 오른쪽 스틱 클릭 카메라 따라가기를 제공합니다.
- 활동층의 주기적인 끊김 조사에서 확인된 반복 카메라 스택 경고 호출을 수정했습니다.
- 게임 설치 폴더를 기준으로 설정과 런타임 파일을 찾도록 배포 구성을 정리했습니다.

### 설정 프로그램

- 버튼 높이와 간격을 맞추고, 작은 창에서 버튼 일부가 잘리는 문제를 수정했습니다.
- 게임 폴더 표시란과 찾기 버튼의 세로 위치를 맞췄습니다.
- 따로 있던 ‘기능 지원’ 탭을 없애고 필요한 설명을 각 설정 옆에 정리했습니다.
- 월드 크기와 입체감·이동 속도의 자동 연동, 시작 시 카메라 따라가기 설정을 추가했습니다.
- 설정은 화질·입체감, 이동·회전, 월드 그립, 활동층 UI, 버튼, 월드 크기의 여섯 탭에서 찾을 수 있습니다.

### 인스톨러

- 네이티브 VR 모듈·설정 프로그램과 필요한 .NET 런타임을 한 설치 묶음으로 제공합니다.
- 지원 게임 파일과 설치 파일을 검사하며, 사용자 설정과 관련 없는 파일을 보존합니다.
- 설치 상태에 따라 설치·업데이트·재설치와 이전 버전 복원 안내가 구분됩니다.
- 설정 프로그램 열기, 작업 진행률과 작업 로그를 보강했습니다.
- 게임 폴더와 패키지 폴더 표시란의 찾기 버튼 정렬을 수정했습니다.

### 사용 안내

설치할 폴더 고르는 방법, 설정 적용과 프로필 사용, 양손 컨트롤러 조작, 업데이트와 복구 방법을 다시 정리했습니다. 자주 생기는 상황은 [문제 해결 안내](TROUBLESHOOTING.md)에서 확인할 수 있습니다.

기기별 호환성, 배포용 바이너리 검증과 실기 확인의 구분은 [확인된 동작과 제한 사항](VERIFICATION.md)을 참고하세요. 업데이트·제거·복구 전에는 게임을 종료하세요.
