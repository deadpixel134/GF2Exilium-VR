# 최근 변경 사항

## 1.0.0 · 2026년 10월 15일

현재 구현의 실기 테스트 완료 확인을 기준으로 첫 정식 버전을 배포합니다. [설치 ZIP과 다운로드 안내](RELEASE_READINESS.md)에서 시작하세요.

### VR 화면과 조작

- 지원되는 3D 장면의 입체 화면, 머리 추적, 정면·보조 패널과 컨트롤러 조작을 포함합니다.
- 월드 크기에 맞춘 입체감·이동 속도 연동, 왼쪽 스틱 클릭 시점 복귀, 오른쪽 스틱 클릭 카메라 따라가기를 제공합니다.
- 활동층의 주기적인 끊김 조사에서 확인된 반복 카메라 스택 경고 호출을 수정했습니다.
- 게임 설치 폴더를 기준으로 설정과 런타임 파일을 찾도록 배포 구성을 정리했습니다.

### 설정 프로그램

- 버튼 높이와 간격을 맞추고, 작은 창에서 버튼 일부가 잘리는 문제를 수정했습니다.
- 게임 폴더 표시란과 찾기 버튼의 세로 위치를 맞췄습니다.
- 따로 있던 ‘기능 지원’ 탭을 없애고 필요한 설명을 각 설정 옆에 정리했습니다.
- 월드 크기와 입체감·이동 속도의 자동 연동, 시작 시 카메라 따라가기 설정을 추가했습니다.
- 설정은 화질·입체감, 이동·회전, 월드 그립, 활동층 UI, 버튼, 월드 크기의 여섯 탭에서 찾을 수 있습니다.

### 인스톨러

- 네이티브 VR 모듈·설정 프로그램과 필요한 .NET 런타임을 한 설치 묶음으로 제공합니다.
- 지원 게임 파일과 설치 파일을 검사하며, 사용자 설정과 관련 없는 파일을 보존합니다.
- 설치 상태에 따라 설치·업데이트·재설치와 이전 버전 복원 안내가 구분됩니다.
- 설정 프로그램 열기, 작업 진행률과 작업 로그를 보강했습니다.
- 게임 폴더와 패키지 폴더 표시란의 찾기 버튼 정렬을 수정했습니다.

### 사용 안내

설치할 폴더 고르는 방법, 설정 적용과 프로필 사용, 양손 컨트롤러 조작, 업데이트와 복구 방법을 다시 정리했습니다. 자주 생기는 상황은 [문제 해결 안내](TROUBLESHOOTING.md)에서 확인할 수 있습니다.

기기별 호환성, 배포용 바이너리 검증과 실기 확인의 구분은 [확인된 동작과 제한 사항](VERIFICATION.md)을 참고하세요. 업데이트·제거·복구 전에는 게임을 종료하세요.
