# 설치·업데이트·제거·복구

## 준비

Windows x64 환경과 정상 실행되는 대상 게임이 필요합니다. 정확한 최소 Windows 버전/깨끗한 PC 수용은 아직입니다. Installer는 지원하는 원본 게임 실행 파일과 엔진/관련 파일10개의 해시를 확인합니다. 다른 게임 버전에서 해시 검사를 우회하지 마세요.

0.4.0 ZIP에는 desktop .NET 런타임을 포함합니다. VR을 사용할 때 필요한 OpenXR/PC VR 연결은 별도로 준비합니다. 현재 사용하는 게임·PC VR 실행 방법을 유지하며, 인스톨러가 게임·SteamVR을 자동 실행하거나 종료하지 않습니다.

## 설치

1. 게임을 정상 종료합니다.
2. ZIP 전체를 빈 폴더에 풉니다. 일부 exe만 꺼내지 않습니다.
3. `GF2VR.Installer.exe`를 열고, `GF2 Game/GF2_Exilium.exe`가 들어 있는 **상위 게임 폴더**를 선택합니다. `GF2 Game` 자체를 root로 선택하지 않습니다.
4. 패키지 폴더가 자동으로 선택되지 않았다면 압축을 푼 manifest가 있는 폴더를 선택합니다.
5. 언어·대상 경로·9개 파일 목록을 확인한 뒤 `설치 / 업데이트`를 누르고 확인합니다.
6. 파일 작업이 끝난 뒤 게임과 PC VR 앱을 직접 실행합니다.

소유권 기록 없는 기존 `version.dll`/OpenXR 로더/설정 도구 파일은 해시가 같아도 덮어쓰지 않습니다. 다른 모드나 개발 설치에 이 패키지를 강제로 적용하지 마세요. 현재 개발용 rollback 자료를 제품 설치 기록으로 바꾸는 작업은 지원하지 않습니다.

## 설치 파일

| 경로 | 내용 |
| --- | --- |
| `GF2 Game/version.dll` | native VR DLL |
| `vrmod/runtime/openxr_loader.dll` | 공식 OpenXR 로더 |
| `vrmod/runtime/openxr-LICENSE.txt` | OpenXR 라이선스 |
| `vrmod/runtime/minhook-LICENSE.txt` | MinHook 라이선스 |
| `vrmod/bin/GF2VR.Configurator/` | 설정 앱 exe·DLL·deps·runtimeconfig·설정 계약, 총5개 |

게임 원본 파일은 확인만 하며 교체하지 않습니다. 사용자 설정과 로그는 패키지에 넣지 않습니다. 설치 기록·중단 상태·transaction backup은 `vrmod/installer/`에 남습니다. 문제가 해결되기 전에 이 폴더를 지우거나 손으로 편집하지 마세요.

## 업데이트

게임을 종료한 뒤 새 패키지를 선택하고 파일 목록을 확인해 `설치 / 업데이트`를 실행합니다. 동일한 제품 scope/파일 집합과 유효한 이전 receipt가 필요합니다. 이전 파일이 외부에서 바뀌었거나 더 낮은 버전/다른 layout이면 거절할 수 있습니다. 자동 다운로드·업데이트는 아직 없습니다.

0.3.0→0.4.0의 같은5/9file layout 업데이트·직전 버전 복구는 임시 폴더에서 확인했습니다. 실제 제품 설치/게임 수용을 대신하는 결과는 아닙니다. .NET private 런타임 갱신도 새 패키지로 수행해야 합니다.

## 제거 / 이전 버전

게임을 종료하고 `제거 / 이전 버전`을 선택합니다. 직전 버전이 있으면 그때의 실제 바이트와 설치 기록을 복구합니다. 최초 설치라면 제품 소유 파일을 제거합니다. 사용자 설정·로그·원본 게임 파일은 보존합니다. 수정된 소유 파일이 발견되면 임의로 제거하지 않습니다.

## 중단 복구

설치/업데이트/제거 중 작업이 중단됐다면 게임을 실행하기 전에 인스톨러의 `중단 복구`를 사용합니다. backup/현재 파일이 바뀌어 복구가 거절되면 transaction 자료를 보존하고 원인을 확인합니다. ZIP 재추출로 backup을 덮어쓰거나 receipt를 손으로 수정하는 방식은 사용하지 않습니다.

설치된 전체 폴더를 파일 탐색기로 옮기면 receipt와 절대 설정 계약이 자동 이식되지 않습니다. 처음부터 사용할 설치 폴더를 선택하세요.
