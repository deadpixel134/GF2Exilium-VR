# 설치·갱신·삭제·복구

검증된 전체 제품 패키지가 있을 때 ZIP전체를 풀고 GF2VR.Installer.exe와 그 옆DLL/deps/runtimeconfig/payload를 함께 유지합니다. 인스톨러의 게임 폴더와 패키지 폴더를 선택한 뒤 파일 목록·버전·상태를 확인합니다. 이 소스 스냅샷에는 최신 전체 제품 패키지가 포함되지 않습니다.

작업 전에 게임을 종료하세요. 설치 기록에 따라 설치/업데이트/다시 설치가 표시됩니다. 제거는 기록된 소유 파일만 처리하며, 이전 버전이 있으면 복구합니다. 중단된 작업은 중단 복구를 사용합니다. 수정되거나 알 수 없는 파일은 강제로 덮어쓰지 않습니다. 사용자 설정과 다른 모드 파일은 보존 대상입니다.

설정 열기는 설치 기록 또는 검증된 개발 launcher의 소유권·payload hash·native계약이 일치할 때 활성화됩니다. 실행 대상이 없거나 불일치하면 비활성화됩니다. 진행률과 작업 로그에서 결과를 확인하고, 게임/SteamVR는 직접 실행합니다. 실제 VR 적용은 설치 성공과 별도입니다.
