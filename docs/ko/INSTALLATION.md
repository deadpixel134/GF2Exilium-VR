# 설치·제거·복구

[한국어](../ko/INSTALLATION.md) | [English](../en/INSTALLATION.md) | [日本語](../ja/INSTALLATION.md) | [简体中文](../zh-CN/INSTALLATION.md)

[정식 버전 1.0.1](https://github.com/deadpixel134/GF2Exilium-VR/releases/tag/v1.0.1)에서 **GF2VR-Native-SelfContained-1.0.1.zip**을 받으세요. GitHub의 **Source code** ZIP은 설치 파일이 아닙니다.

## 설치 전 준비

- Windows x64 PC에서 정식 설치한 게임과 VR 환경이 필요합니다. **2.0.3936**은 실기 확인 기준 빌드입니다. 원본 게임의 SHA-256·파일 크기·캐시 차이만으로 설치를 막지 않지만, 다른 게임 버전의 VR 동작을 보장하는 것은 아닙니다.
- 게임을 완전히 종료합니다.
- 내려받은 압축 파일을 새 폴더에 전부 풉니다. ZIP 안에서 바로 실행하지 마세요.
- 인스톨러 실행 파일만 따로 옮기지 말고 함께 들어 있는 파일과 폴더를 그대로 둡니다.

필요한 .NET 런타임은 설치 묶음에 포함되어 있습니다. 게임·헤드셋 소프트웨어·SteamVR는 별도로 준비해야 합니다.

## 설치하기

1. 압축을 푼 폴더에서 **GF2VR.Installer.exe**를 실행합니다.
2. **게임 폴더** 오른쪽의 **찾기…**를 누릅니다. **GF2_Exilium.exe가 있는 폴더** 또는 이를 포함하는 설치 폴더를 선택하세요. 폴더 이름과 하위 구조가 달라도 실행 파일을 찾습니다. 여러 개를 찾으면 설치할 실행 파일에 더 가까운 폴더를 선택하세요.
3. **패키지 폴더**가 비어 있다면 ZIP을 푼 폴더를 선택합니다. 인스톨러와 package-manifest.json 파일, payload 폴더가 같은 위치에 있는지 확인하세요. 파일을 직접 수정할 필요는 없습니다.
4. 화면에 표시되는 버전과 처리할 파일 목록을 확인합니다. **설정 프로그램만 설치한다는 안내**가 나온다면 VR 모드 전체를 설치하는 묶음이 아닙니다.
5. **설치**를 누르고, 표시된 위치가 맞으면 확인합니다. 이미 설치된 상태에 따라 **업데이트** 또는 **재설치**로 표시될 수 있습니다.
6. 완료 메시지가 나올 때까지 기다립니다. 작업이 끝나면 **설정 열기**로 설정 프로그램을 열 수 있습니다.

진행 중에는 인스톨러를 닫거나 설치 파일을 이동하지 마세요. 완료 후 게임과 SteamVR는 직접 실행합니다. 설정부터 확인하려면 [설정 안내](SETTINGS.md)를 참고하세요.

다른 프로그램의 version.dll이 이미 있거나 제품 패키지의 해시·소유권 검사가 실패하면 설치가 거절될 수 있습니다. 원본 게임의 해시 차이만으로 거절하지 않습니다. 기존 파일을 덮어쓰거나 삭제해 우회하지 말고 [문제 해결 안내](TROUBLESHOOTING.md)를 확인하세요.

`GF2 Game/GF2_Exilium.exe` 구조에서는 기존 상위 폴더의 `vrmod`를 유지합니다. 그 외 구조에서는 찾은 실행 파일 폴더의 `vrmod`를 사용합니다. `version.dll`은 항상 해당 실행 파일 옆에 설치됩니다.

## 화면의 버튼 알아보기

| 버튼 | 하는 일 |
|---|---|
| 설치·업데이트·재설치 | 선택한 설치 파일을 게임 폴더에 적용합니다. |
| 설정 열기 | 현재 설치와 맞는 설정 프로그램을 엽니다. 사용할 수 없을 때는 비활성화됩니다. |
| 다시 확인 | 선택한 폴더와 설치 상태를 다시 확인합니다. |
| 제거 | 인스톨러가 설치한 파일을 처리합니다. 이전 버전이 남아 있으면 그 버전으로 돌아갈 수 있습니다. |
| 중단 복구 | 설치나 제거가 도중에 멈췄을 때 이전 파일 상태로 복구합니다. |

## 제거하거나 이전 버전으로 돌아가기

게임을 종료한 뒤 인스톨러에서 게임 폴더를 확인하고 제거 관련 버튼을 누릅니다. 이전 버전이 보관되어 있으면 **직전 버전 복귀**로 표시됩니다. 화면의 확인 메시지를 읽고 진행하세요.

처음 설치한 상태에서 제거하면 인스톨러가 관리하는 파일만 삭제하며, 사용자 설정과 다른 모드 파일은 남깁니다. 이전 버전으로 복구했다면 모드가 완전히 제거된 상태와는 다릅니다.

수정된 파일 때문에 작업이 거절되면 파일을 강제로 삭제하지 말고 [문제 해결 안내](TROUBLESHOOTING.md)를 확인하세요.

## 작업이 중간에 멈췄다면

1. 게임이 종료되어 있는지 확인합니다.
2. 같은 게임 폴더로 인스톨러를 다시 엽니다.
3. **중단 복구**가 활성화되어 있다면 실행합니다.
4. 결과를 확인한 뒤 설치나 제거를 다시 진행합니다.

**중단 복구**는 멈춘 작업을 정리하는 기능이고, **이전 버전 복원**은 설치되어 있던 버전으로 돌아가는 기능입니다. 복구가 실패했다면 반복해서 파일을 바꾸기보다 오류 메시지와 작업 로그를 확인하세요.
