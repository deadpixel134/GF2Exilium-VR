# 설정 프로그램

설치 후 `vrmod/bin/GF2VR.Configurator/GF2VR.Configurator.exe`를 실행합니다. 앱이 설치 DLL 해시와 설정 root를 확인한 뒤 현재 설정을 읽습니다. 게임을 종료한 상태에서 저장하고, 적용하려면 게임을 직접 다시 시작합니다. 저장 성공은 VR에서 실제 적용됐다는 수용 결과가 아닙니다.

## 현재 제공하는 설정

| 항목 | 의미 / 기본값 |
| --- | --- |
| VR 렌더 해상도 배율 | 기본1.0. 기존0.6 설정은 설치/업데이트가 변경하지 않음. PC·보조 패널 해상도와 별개 |
| Stereo Depth / 눈 간격 배율 | 기본1.0. 게임 월드의 stereo depth 조정이며 HMD 물리 IPD 변경이 아님 |
| 이동·회전 사용 | 기본 둘 다 ON |
| 이동 손 | 기본 왼쪽. 다른 손이 회전을 담당하여 좌우 역할을 함께 바꿈 |
| 회전 방식 | 기본 Snap. Smooth 선택 가능 |
| 이동 속도 / 이동 배수 | 기본 각각1.0. 배수는 이동 속도에 곱하며 world scale이 아님 |
| Snap 각도 / Smooth 속도 / 스틱 deadzone | 기본30° /60°·s⁻¹ /0.2 |
| World Drag | 설정이 없으면 OFF. 좌/우 Grip·Trigger 활성화와 추적 손 선택 제공 |

해상도·depth·속도 등 수치는 권장 범위를 강제 제한으로 사용하지 않습니다. 형식 오류/비유한 값/기능이 표현할 수 없는 값은 거절될 수 있습니다. 해상도1.0 기준0.6은 가로·세로 각각의 비율이므로 픽셀 수는 약36%지만, 성능 개선 비율을 보장하지는 않습니다.

## 저장과 프로필

- `다시 읽기`: 디스크에 저장된 상태를 읽습니다. 저장하지 않은 수정은 확인 후 버립니다.
- `기본값`: 현재 편집값의 알려진 항목을 기본값으로 바꿉니다. **저장하기 전에는 runtime 설정 파일을 바꾸지 않습니다.**
- `가져오기`: 프로필의 알려진 설정을 편집값에 적용합니다. 저장 전까지 runtime 파일을 바꾸지 않습니다.
- `내보내기`: 현재 편집값을 프로필 파일에 내보냅니다. 게임에 적용하는 버튼이 아닙니다.
- `저장`: 검증된 편집값을 설정 파일에 씁니다. game running/외부 파일 변경/잘못된 root·DLL 계약 등은 거절할 수 있습니다.

runtime 설정은 `vrmod/config/render_quality.json`, `stereo_depth.json`, `navigation.json`, `world_drag.json`입니다. 설정 앱은 지원하는 호환 unknown 항목을 보존하지만 잘못된 known 항목이나 잘못된 JSON을 자동 복구한다고 주장하지 않습니다. 설정이 손상됐다면 먼저 원본을 보관하고 [문제 해결](TROUBLESHOOTING.md)을 확인하세요.

한국어·영어·일본어를 선택할 수 있습니다. 미구현/아직 연결되지 않은 기능은 대응 기능 화면에 안내하며 가짜 조작 항목을 제공하지 않습니다. 모든 VFX의 독립 토글, WorldScale/Follow, 아직 배포되지 않은 face 설정, 활동층 주 화면 UI 토글을 현재 앱의 완성된 기능으로 보지 마세요.
