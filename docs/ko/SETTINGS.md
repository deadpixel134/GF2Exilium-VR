# 설정 프로그램 사용하기

[한국어](../ko/SETTINGS.md) | [English](../en/SETTINGS.md) | [日本語](../ja/SETTINGS.md) | [简体中文](../zh-CN/SETTINGS.md)

[처음으로](../../README.md)

인스톨러의 **설정 열기**로 설정 프로그램을 엽니다. 설치된 게임 폴더의 `vrmod/bin/GF2VR.Configurator/GF2VR.Configurator.exe`로 직접 열 수도 있습니다. 실행 파일과 함께 설치된 파일은 같은 폴더에 유지하세요. 표시 언어는 아래쪽의 **한국어 / English / 日本語** 버튼으로 바꿀 수 있으며 선택은 기억됩니다.

## 바꾼 설정 적용하기

1. 게임을 종료합니다.
2. 원하는 항목을 조정합니다. 항목 아래의 설명도 함께 확인하세요.
3. **저장**을 누르고 완료 메시지를 확인합니다.
4. 게임을 직접 다시 실행합니다.

설정 창에서 숫자를 바꾸는 것만으로 실행 중인 게임에 바로 적용되지는 않습니다. 숫자에는 단위를 붙이지 말고 소수점은 점으로 입력하세요. 예를 들어 0.5처럼 적습니다.

## 화질·입체감

**VR 렌더 해상도 배율**은 VR 화면을 그리는 해상도입니다. 값을 높이면 더 선명해질 수 있지만 성능과 메모리 부담도 늘어납니다. 낮추면 화면이 흐려질 수 있습니다. PC 화면이나 보조 패널의 해상도를 바꾸는 설정은 아닙니다.

기본값은 1.0입니다. 문제가 생기면 이전에 정상 동작하던 값으로 돌아가세요. 모든 장치에서 같은 값이 적용되는 것은 아닙니다. 시각 효과는 게임 기본값을 사용하며, 효과별 켜기·끄기 항목은 제공하지 않습니다.

## 월드 크기

**월드 크기 배율**은 주변 세계가 느껴지는 크기를 조절합니다. **1은 100%, 2는 200%, 0.5는 50%**입니다. 200%로 설정하려면 숫자 2를 입력하세요.

| 설정 | 설명 |
|---|---|
| 월드 크기 배율 | 세계의 크기를 조절합니다. 처음에는 기본값 1에서 조금씩 바꿔 보세요. |
| Stereo Depth를 월드 크기에 연동 | 월드 크기에 맞춰 양쪽 눈의 게임 속 간격을 자동으로 맞춥니다. 기본은 켜짐입니다. |
| Stereo Depth / 눈 간격 배율 | 입체감을 정하는 게임 속 눈 간격을 수동으로 조절합니다. 자동 연동 중에는 현재 값만 표시되고 직접 편집할 수 없습니다. |
| 이동 속도를 월드 크기에 연동 | 세계를 크게 하면 이동도 그만큼 빠르게, 작게 하면 그만큼 느리게 조절합니다. 기본은 켜짐입니다. |

눈 간격 자동 연동을 끄면 그때의 계산값을 시작점으로 직접 조절할 수 있습니다. 다시 켜면 현재 월드 크기에 맞춰 자동으로 계산합니다. 이 설정은 헤드셋 자체의 눈 간격 조절을 대신하지 않습니다.

이동 속도 연동을 꺼도 **이동·회전** 탭의 기본 속도와 수동 배율은 유지됩니다. 월드 크기에 따른 자동 조절만 빠집니다.

화면 아래의 **머리 이동** 표시는 월드 크기에 맞춰 머리 움직임을 보정한 값입니다. 스틱 이동 속도를 뜻하지 않으며 따로 입력하는 항목도 아닙니다.

## 이동·회전

| 설정 | 설명 |
|---|---|
| 스틱 이동 사용 | 컨트롤러 스틱으로 VR 시점을 이동할지 정합니다. |
| 이동에 사용할 손 | 기본은 왼손입니다. 바꾸면 이동과 회전 스틱의 역할이 함께 교환됩니다. |
| 스틱 회전 사용 | 반대 손의 스틱으로 시야를 회전할지 정합니다. |
| 회전 방식 | 스냅은 일정 각도씩 돌고, 부드러운 회전은 스틱을 기울인 동안 계속 회전합니다. |
| 이동 속도 | 스틱으로 이동하는 기본 속도입니다. 기본값은 1.0입니다. |
| 이동 속도 수동 배율 | 기본 이동 속도를 얼마나 빠르거나 느리게 할지 조절합니다. 1.0은 그대로, 2는 두 배, 0.5는 절반입니다. |
| 스냅 회전 각도 | 스냅 방식에서 한 번에 돌아가는 각도입니다. 기본값은 30°입니다. |
| 부드러운 회전 속도 | 연속 회전의 빠르기입니다. 스냅 방식에서는 사용하지 않습니다. |
| 스틱 데드존 | 스틱의 작은 흔들림을 무시하는 범위입니다. 손을 떼도 움직인다면 이 항목을 확인하세요. |
| 시작 시 카메라 연출 따라가기 | 게임 시작 시 원래 카메라의 움직임을 따라갈지 정합니다. 기본은 켜짐입니다. |

이동 손을 바꾸는 것과 **버튼** 탭의 패널·포인터 손 교환은 서로 다른 설정입니다.

실행 중 **오른쪽 스틱 클릭**으로 카메라 따라가기를 바꿔도 저장된 시작 설정은 바뀌지 않습니다. 다음 게임 실행 때도 같은 상태로 시작하려면 이 창에서 저장하세요.

## 월드 그립

월드 그립은 버튼을 누른 채 손을 움직여 VR 시점을 옮기는 기능입니다. 기본적으로 꺼져 있으므로 사용하려면 먼저 켜야 합니다.

- **월드 그립 사용**: 기능을 켜거나 끕니다.
- **활성화 버튼**: 왼쪽·오른쪽의 Grip 또는 Trigger 중 사용할 버튼을 선택합니다.
- **추적할 손**: 어느 손의 움직임을 기준으로 할지 선택합니다.

활성화 버튼과 추적할 손을 각각 하나 이상 선택해야 합니다. 기본 선택은 오른쪽 Grip과 오른손 추적입니다.

보조 패널을 담당하는 손의 Grip은 패널 열기·닫기가 우선입니다. 같은 손의 Trigger는 게임 조작 모드에 사용하고, 포인터 손의 Trigger는 UI 조작이 우선합니다. 처음에는 기본 오른쪽 Grip 조합으로 사용 방법을 익히는 편이 이해하기 쉽습니다.

## 손 표시

흰색 구 형태의 양손 표시는 Clean·Dirty 공통이며 기본 켜짐입니다. 손 표시 탭에서 조절합니다. Clean에는 캐릭터 접촉 변형이 포함되지 않습니다.

## 보조패널 — 공통

사용자 바라보기와 수동 각도의 동시 적용 여부를 각각 선택합니다. 수동 각도 적용을 끄면 사용자 바라보기를 껐을 때만 Yaw/Pitch/Roll과 화면 기울기가 적용되며, 비활성화된 값도 보관합니다. 위치와 최대 너비·높이는 항상 적용합니다. 최대 크기 안에서 원본 화면 비율을 유지합니다.

기본값: 사용자 바라보기 ON, 수동 각도 동시 적용 OFF. 위치 X/Y/Z = 0 / -0.10 / 0.01m, Pitch/Yaw/Roll = -67 / 3 / 0도, 화면 기울기 45도, 최대 너비·높이 각각 0.66m.

위치는 컨트롤러 로컬 축을 따릅니다. 관찰된 평소 쥔 자세에서는 +X 오른쪽 / +Y 앞 / +Z 위이며, 손을 회전하면 이동 축도 함께 회전합니다. 화면 기울기는 최종 화면의 가로축을 기준으로 +는 위, -는 아래입니다. 기존 설정에 auxiliaryPanel 객체가 없으면 이전 배치를 유지하며 보조패널 항목을 저장하거나 기본값을 적용할 때 새 설정을 사용합니다.

## 접촉 피드백 — Dirty

손 표시 탭에서 접촉 진동 세기·시간을 조절합니다. 최초 접촉 때 한 번 울리고 완전히 떼었다 다시 닿으면 재동작합니다. 진동 기본값은 15% / 30ms이며 0은 끄기입니다.

접촉 흔들림 탭은 가슴·엉덩이를 별도로 조절합니다. 순서는 세기 / 지속 / 범위 / 기울기 / 늘어남입니다.

| 부위 | 기본값 |
|---|---|
| 가슴 | 40% / 0.4배 / 75% / 50% / 45% |
| 엉덩이 | 120% / 0.5배 / 120% / 120% / 140% |

저장된 명시적 설정을 보존합니다. 이전 공통 값보다 부위별 값이 우선합니다. 임의 상한은 없으며 유효한 숫자·양수 지속·양의 압축 스케일 등 필수 검사는 유지합니다. 저장 후 게임을 재시작하세요.

## 활동층 UI

**주 화면 활동층 UI 표시**를 끄면 주 VR 화면에 겹쳐 보이는 활동층 UI를 숨깁니다. 3D 화면과 원본 게임 화면을 보여 주는 보조 패널은 유지됩니다.

켜 둔 경우에도 보조 패널을 열면 주 화면 UI는 잠시 숨고, 보조 패널을 닫으면 다시 나타납니다.

## 버튼

| 설정 | 꺼짐: 기본 | 켜짐 |
|---|---|---|
| 클릭·뒤로가기 버튼 교환 | 포인터 손의 A 또는 X가 클릭, B 또는 Y가 뒤로 가기 | 두 동작을 서로 바꿉니다. |
| 패널·포인터 손 교환 | 왼손이 보조 패널, 오른손이 포인터 | 오른손이 보조 패널, 왼손이 포인터 |

패널 손을 바꾸면 패널을 여닫는 Grip과 게임 조작 모드용 Trigger도 해당 손으로 옮겨갑니다. 스틱 이동·회전 손은 이 설정으로 바뀌지 않습니다.

게임 조작 모드의 **X/A → F, Y/B → Escape** 입력은 일반 클릭·뒤로가기 교환과 별개입니다.

## 진단과 로그

**진단 → 로그 자동 기록**의 기본값은 OFF입니다. 문제 분석이 필요할 때 켜고 저장한 뒤 게임을 다시 실행하세요. ON에서는 로그가 계속 추가되어 용량이 커질 수 있습니다.

업그레이드 시 최초 정리 대상으로 판단된 기존 VR 자동 로그만 한 번 정리합니다. 명시적 ON 사용자는 기존 로그를 보존하고 이 정리에서 제외되며, 나중에 OFF로 바꿔도 그 과거 로그를 뒤늦게 삭제하지 않습니다. 사용자 설정·다른 모드 파일·수동 수집 자료는 보존합니다.

## 저장·프로필 버튼

| 버튼 | 사용 방법 |
|---|---|
| 저장 | 현재 편집한 설정을 저장합니다. 적용하려면 게임을 다시 실행하세요. |
| 다시 읽기 | 마지막으로 저장된 설정을 다시 불러옵니다. 저장하지 않은 변경은 사라집니다. |
| 기본값 | 설정 항목을 기본값으로 돌립니다. 적용하려면 이어서 저장하세요. |
| 내보내기 | 현재 설정을 별도의 프로필 파일로 보관합니다. 여러 조합을 번갈아 쓰거나 백업할 때 사용할 수 있습니다. |
| 가져오기 | 저장한 프로필을 불러옵니다. 내용을 확인한 뒤 저장해야 게임 설정에 반영됩니다. |

수치 옆의 권장 범위는 조절을 시작할 때 참고하는 안내입니다. 권장 범위를 벗어난 입력을 무조건 막지는 않지만, 장치나 기능이 처리할 수 없는 값은 적용되지 않을 수 있습니다. 오류가 나면 메시지를 확인하고 이전 값이나 기본값으로 돌아가세요.
