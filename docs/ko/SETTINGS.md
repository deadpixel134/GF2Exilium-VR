# 설정 GUI

화질·입체감, 이동·회전, 월드 그립, 활동층 UI, 버튼, 월드 크기의6개 탭에25개 설정을 제공합니다. 별도 기능 지원 탭은 없고 도움말은 해당 설정 옆에 있습니다. 한국어/English/日本語 선택은 저장되며 알 수 없는 언어는 한국어로 대체됩니다.

- 화질: VR 렌더 해상도 배율. PC/보조 패널 해상도와 독립적입니다. 시각 효과는 게임 기본값을 따르며 개별 효과 스위치는 없습니다.
- 이동·회전: 스틱 사용, 손 역할, 스냅/연속 회전, 속도/수동 배율, 데드존과 시작 시 카메라 따라가기. 저장한 따라가기는 다음 게임 실행부터 적용되고 오른쪽 스틱 클릭은 실행 중 상태만 전환합니다.
- 월드 그립: 사용 여부, 활성화 버튼, 추적 손. 패널Grip/Trigger 우선순위는 해당 도움말을 확인하세요.
- 활동층 UI: 주 화면 활동층 UI 표시. 보조 패널은 독립적입니다.
- 버튼: 구현된 클릭/뒤로가기 교환과 패널/포인터 손 교환.
- 월드 크기: 1=100%,2=200%,0.5=50%. 눈 간격 자동 연동은1/월드배율, 이동 속도 자동 연동은월드배율입니다. 깊이 연동을 끄면 현재 계산값부터 수동 편집합니다. 머리 이동 보정은1/월드배율이며 스틱 속도와 구별됩니다.

저장 전에 게임을 종료하고 저장 후 직접 다시 실행하세요. 저장 성공이 실제 VR적용을 증명하지는 않습니다. 다시 읽기는 파일을 읽고, 기본값/가져오기는 저장 전 편집 상태를 바꿉니다. 내보내기는 프로필을 만듭니다. 호환되는 알 수 없는 설정은 보존하며 손상된 값은 명시적으로 거절합니다. 권장 수치 범위는 안내이고 직접 입력을 그 경계로 강제 보정하지 않습니다. 잘못된 형식·비유한 값·실제 backend가 적용할 수 없는 값은 실패할 수 있습니다.
