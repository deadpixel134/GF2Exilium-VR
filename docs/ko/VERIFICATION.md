# 확인된 동작과 제한 사항

사용할 수 있는 기능과 아직 직접 사용 확인이 남아 있는 부분을 안내합니다. 프로그램 점검을 마쳤다는 것과 실제 VR 화면에서의 확인은 서로 다릅니다.

## 설정 프로그램과 인스톨러

별도의 테스트 폴더에서 다음 동작을 확인했습니다.

- 설정 저장·불러오기, 기본값과 프로필 가져오기·내보내기
- 잘못된 설정값에 대한 오류 안내와 언어 선택 유지
- 설치·업데이트·제거, 이전 버전 복원과 중단 복구
- 기존 설정과 다른 파일을 보존하는 동작
- 진행률·작업 로그, 인스톨러에서 맞는 설정 프로그램을 찾는 동작
- 세 언어 화면과 작은 창·확대한 배치에서의 버튼 정렬

이 점검에서는 실제 게임 파일이나 사용자 설정을 바꾸지 않았습니다.

## 게임 안에서 확인한 기능

기존 테스트에서 일부 지원 장면의 입체 화면, 보조 패널과 UI 조작, 스틱 이동·회전, 월드 그립, 활동층 UI 표시 설정, 게임 조작 모드의 WASD·F·Escape 입력을 확인했습니다.

모든 장면과 장면 전환, 모든 버튼 조합과 장치 환경을 확인한 것은 아닙니다. 문제가 생기면 어떤 장면과 조작에서 발생했는지 [문제 해결 안내](TROUBLESHOOTING.md)에 따라 정리해 주세요.

## 실제 VR 사용 확인이 남아 있는 기능

- 월드 크기를 바꿨을 때의 화면·머리 움직임·입체감과 이동 속도 연동
- 왼쪽 스틱 클릭으로 원본 카메라 기준 시점으로 돌아간 뒤 다시 이동하는 동작
- 오른쪽 스틱 클릭과 시작 설정을 이용한 카메라 따라가기 전환
- 최신 전체 설치 파일을 다른 설치 환경에 적용하고 실행하는 과정

설정과 조작은 제공되지만 실제 VR 환경에서의 사용 확인은 아직 끝나지 않았습니다.

## 업데이트와 배포

설치 파일을 검사하고 문제가 생기면 기존 버전으로 돌아가는 동작은 테스트 폴더에서 확인했습니다. 실제 정식 릴리스를 내려받아 업데이트하는 과정과 다른 사용자의 비공개 저장소 접근 방법은 아직 확인·정리가 끝나지 않았습니다.

다운로드 가능 여부는 [다운로드와 지원 안내](RELEASE_READINESS.md)에서 확인하세요.
