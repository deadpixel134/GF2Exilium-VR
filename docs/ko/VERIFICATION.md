# 확인된 동작과 제한 사항

정식 버전 1.0.0의 지원 대상과 확인 범위를 안내합니다. 현재 구현에 대한 사용자의 실기 확인, 배포 파일의 로컬 검증, 다른 PC에서의 확인은 구분합니다.

## 지원 대상

Windows x64 PC용 GF2 Exilium **2.0.3936**을 대상으로 하며, 인스톨러가 원본 게임 파일의 지문을 확인합니다. 게임 업데이트로 파일이 바뀌면 새 호환 릴리스가 필요할 수 있습니다. 모든 HMD·컨트롤러·연결 방식에 대한 호환성 목록은 제공하지 않습니다.

## 설정 프로그램과 인스톨러

별도의 테스트 폴더에서 다음 동작을 확인했습니다.

- 설정 저장·불러오기, 기본값과 프로필 가져오기·내보내기
- 잘못된 설정값에 대한 오류 안내와 언어 선택 유지
- 설치·업데이트·제거, 이전 버전 복원과 중단 복구
- 기존 설정과 다른 파일을 보존하는 동작
- 진행률·작업 로그, 인스톨러에서 맞는 설정 프로그램을 찾는 동작
- 세 언어 화면과 작은 창·확대한 배치에서의 버튼 정렬

이 점검에서는 실제 게임 파일이나 사용자 설정을 바꾸지 않았습니다.

## 현재 구현의 실기 확인

지원 장면의 입체 화면, 보조 패널과 UI 조작, 스틱 이동·회전, 월드 그립, 활동층 UI 표시 설정, 게임 조작 모드의 WASD·F·Escape 입력을 실기 확인해 왔습니다. 월드 크기 연동, 왼쪽 스틱 클릭의 시점 복귀, 오른쪽 스틱 클릭의 카메라 따라가기와 현재 설정·인스톨러 화면을 포함한 구현은 사용자의 테스트 완료 확인을 기준으로 정식 버전에 고정했습니다.

활동층에서 2~4초 간격으로 보고됐던 끊김과 관련해 반복 카메라 경고를 발생시키던 호출을 수정했습니다. 이후 게임 로그에서는 해당 경고가 발생하지 않았고, 사용자는 현재 구현을 안정 버전으로 선택했습니다. 수치로 측정한 최소 프레임 속도나 모든 상황의 무중단 동작을 보증하는 의미는 아닙니다.

## 배포 파일 검증과 한계

배포용 네이티브 모듈은 위 구현의 렌더링·입력 코드를 유지하면서 게임 설치 폴더를 기준으로 파일을 찾도록 구성했습니다. 경로 이동, Windows API 호출, 내보내기 항목과 파일 무결성을 로컬에서 검사했습니다. 이 배포용 바이너리 자체를 새로 게임/HMD에서 실행한 결과는 별도로 기록하지 않았습니다.

필요한 .NET 런타임을 함께 제공하지만, .NET이 없는 새 Windows PC에서 설치부터 HMD 실행까지 전체 과정을 새로 검증한 것은 아닙니다. 모든 장면 전환과 버튼 조합도 포괄하지 않습니다.

## 업데이트와 배포

패키지 검사·설치·업데이트·이전 버전 복원은 테스트 폴더에서 확인했습니다. 1.0.0은 첫 정식 릴리스이므로 이후 정식 버전으로의 실제 사용자 업데이트 완료 이력은 아직 없습니다. 새 버전을 받아 적용할 때도 기존 설치 검사와 복구 절차를 사용합니다.

문제가 생기면 장면·조작·장치 환경과 오류 메시지를 [문제 해결 안내](TROUBLESHOOTING.md)에 따라 정리해 주세요. 다운로드는 [릴리스 안내](RELEASE_READINESS.md)를 참고하세요.
