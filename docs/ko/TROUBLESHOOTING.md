# 문제 해결

| 증상 / 안내 | 확인할 것 |
| --- | --- |
| 실행 파일을 열어도 앱이 시작되지 않음 | ZIP 전체를 풀었는지, exe 옆의 앱 DLL/deps/runtimeconfig가 함께 있는지 확인. 0.4.0은 private .NET을 포함하지만 모든 Windows/보안 정책 환경을 검증한 것은 아님 |
| 게임 폴더를 찾지 못함 | `GF2 Game/GF2_Exilium.exe`가 있는 상위 root를 선택. 다른 exe/빈 폴더 선택 금지 |
| 원본 게임 / 패키지 해시 불일치 | 지원 원본 버전과 패키지 손상 여부 확인. 검사 우회를 위해 게임 파일을 덮어쓰지 않음 |
| 기존 DLL/도구를 수정된 파일로 거절 | Installer 소유권 기록이 없는 파일도 거절할 수 있음. 다른 모드/개발 설치를 자동으로 인수하지 않음 |
| 설정 앱의 DLL/root 계약 불일치 | 설치된 앱을 사용하고 folder move/다른 빌드/변경된 runtime-contract 여부 확인. 해시를 손으로 바꿔 성공처럼 만들지 않음 |
| 게임 실행 중이라 작업 거절 | 게임을 정상 종료한 뒤 다시 선택. 도구는 게임을 강제 종료하지 않음 |
| 저장 후 적용되지 않음 | 저장이 완료됐는지 확인하고 게임을 직접 재시작. GUI 저장 성공과 실제 VR 적용은 구분 |
| JSON/수치 오류 | 원본 설정 파일을 별도 보관한 뒤 알려진 잘못된 항목 확인. 기본값/가져오기는 편집만 변경하며 이후 저장이 필요 |
| 외부에서 파일이 바뀌어 저장/설치/제거 거절 | 새 상태를 다시 읽어 원인을 확인. backup/현재 자료를 보존하고 강제 덮어쓰기 금지 |
| 중단 상태 / 복구 필요 | 게임 실행 전 `중단 복구` 사용. `vrmod/installer/transactions`를 삭제하지 않음 |
| VR/활동층 UI/카메라/프레임 문제 | 새 패키지의 게임·VR 수용은 미완료. 화면/재현 순서/빌드/FPS 표시 출처를 구분해 기록 |

설치 후보에 자동 업데이트/바이너리 다운로드/지원 문의 endpoint는 없습니다. private 저장소는 deadpixel134/GF2Exilium-VR입니다. 오류 기록을 외부에 공유하려면 계정 정보/개인 경로/토큰 등 민감한 내용을 확인하고 필요한 부분만 제공하세요. 개발용 내부 로그나 복구 파일 전체를 배포 소스에 넣지 않습니다.
