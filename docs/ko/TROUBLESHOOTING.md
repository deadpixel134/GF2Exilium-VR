# 문제가 생겼을 때

먼저 어느 작업에서 문제가 생겼는지 확인하세요. 설정 저장 문제인지, 설치·업데이트 문제인지, 실제 VR 화면·입력 문제인지에 따라 확인할 부분이 다릅니다.

## 게임 폴더를 찾을 수 없다고 나옵니다

인스톨러에서는 **GF2 Game 폴더가 들어 있는 상위 폴더**를 선택해야 합니다. GF2 Game 안에 GF2_Exilium.exe가 있는지 확인하세요. 게임 폴더와 설치 압축을 푼 패키지 폴더를 서로 바꿔 선택하지 않았는지도 확인합니다.

## 패키지 파일이 없거나 설치할 수 없다고 나옵니다

- ZIP을 먼저 전부 풀었는지 확인합니다.
- 실행 파일만 따로 옮기지 않았는지 확인합니다.
- GitHub의 코드 다운로드 ZIP을 설치 파일로 사용하고 있지 않은지 확인합니다.
- 전달받은 설치 파일이 현재 게임과 맞는지 확인합니다. 다른 경로나 다른 게임 버전용이라는 메시지가 나오면 강제로 진행하지 마세요.

파일이 빠졌거나 손상되었다면 원래 전달받은 묶음을 새 폴더에 다시 풀어 비교하세요. 인스톨러가 거절한 파일을 임의로 수정해 검사를 통과시키지 마세요.

## ‘설정 열기’ 버튼이 비활성화되어 있습니다

현재 게임에 맞는 설정 프로그램을 찾지 못한 상태입니다. 게임 폴더가 맞는지 확인하고 **다시 확인**을 누르세요. 설정 프로그램만 또는 인스톨러만 별도로 복사했다면 함께 제공된 파일이 빠졌을 수 있습니다.

안내받은 실행 경로가 있다면 그 경로로 열어 보세요. 해결되지 않으면 프로그램과 설치 파일을 뒤섞기보다 오류 안내를 확인하세요.

## 저장이나 설치를 할 수 없습니다

게임이 완전히 종료되었는지 먼저 확인합니다. 창만 닫았어도 게임이 아직 실행 중일 수 있습니다.

숫자 오류가 나오면 입력란에 단위나 문자를 넣지 않았는지 확인하세요. 소수점은 점으로 입력합니다. 값이 너무 크거나 장치에서 처리할 수 없다면 이전 값이나 기본값으로 돌아가세요.

파일 접근 오류가 나오면 표시된 폴더가 맞는지 확인하고, 다른 프로그램이 해당 파일을 사용 중인지 확인하세요. 수정된 파일을 보호하기 위해 작업을 멈춘 경우에는 그 파일을 먼저 백업하고 어떤 변경이 있었는지 확인합니다.

## 저장했는데 게임에서 달라지지 않습니다

저장 후 게임을 종료했다가 다시 실행했는지 확인합니다. 프로필을 가져오거나 기본값을 누른 뒤에도 **저장**이 필요합니다.

오른쪽 스틱 클릭으로 바꾼 카메라 따라가기는 현재 게임에만 적용됩니다. 다음 실행의 시작 상태를 바꾸려면 설정 프로그램에서 저장해야 합니다.

## 보조 패널·클릭·스틱 조작이 예상과 다릅니다

1. 컨트롤러가 정상적으로 연결되어 있는지 확인합니다.
2. PC에서 게임 창을 선택합니다.
3. 이동·회전 손과 패널·포인터 손을 바꾸지 않았는지 설정을 확인합니다.
4. 보조 패널 손의 Trigger를 누르고 있다면 놓아 보세요. 누르는 동안에는 WASD 게임 조작 모드가 됩니다.
5. 스냅 회전은 스틱을 가운데로 놓은 뒤 다시 기울입니다.

보조 패널은 3D 화면에서 패널 손의 Grip으로 여닫습니다. 일반 2D 화면의 정면 패널은 이 조작으로 숨겨지지 않습니다. [조작법](USAGE.md)을 참고하세요.

## 월드 그립이 움직이지 않습니다

기능은 기본적으로 꺼져 있습니다. 설정에서 사용을 켜고, 활성화 버튼과 추적할 손을 각각 하나 이상 고른 뒤 저장·재실행했는지 확인합니다.

다른 패널·UI 조작이 먼저 동작하는 조합이라면 기본 오른쪽 Grip과 오른손 추적으로 확인해 보세요. 누르고 있던 버튼은 놓았다가 다시 누릅니다.

## 업데이트를 확인할 수 없습니다

인터넷 연결, 비공개 저장소의 접근 권한, 실제 새 버전 제공 여부를 확인합니다. 업데이트를 확인하지 못해도 기존 설정과 설치를 계속 사용할 수 있도록 되어 있습니다. [업데이트 안내](UPDATE.md)를 참고하세요.

## 설치가 멈췄거나 새 버전에서 문제가 생겼습니다

게임을 종료한 뒤 같은 폴더로 인스톨러를 다시 엽니다. 중단된 작업이 있다면 **중단 복구**를 사용합니다. 업데이트를 완료한 뒤 문제가 생겼다면 이전 버전 복원 안내를 확인합니다. [제거·복구 안내](INSTALLATION.md)를 참고하세요.

## 문제를 전달할 때

어느 버튼을 눌렀는지, 어떤 순서에서 발생했는지, 오류 메시지, 사용 중인 헤드셋과 연결 방법을 함께 알려 주세요. 설치 문제라면 작업 로그에서 마지막으로 표시된 내용을 확인하면 도움이 됩니다.

화면이나 파일을 공유하기 전에는 계정 정보와 인증 정보가 들어 있지 않은지 확인하세요. 원본 게임 파일을 통째로 전달할 필요는 없습니다.
