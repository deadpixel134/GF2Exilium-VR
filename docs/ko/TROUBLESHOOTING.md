# 문제 해결

설정 열기가 비활성화되면 GUI파일·소유 기록·설치된native계약이 맞는지 확인하세요. source의 template계약은 작동용이 아닙니다. 파일을 임의로 다른설치에 복사해 hash검사를 우회하지 마세요.

저장/설치가 게임 실행 중 거절되면 먼저 게임을 종료합니다. 경로·파일이 수정되었거나 손상되었으면 원인을 확인하고 소유권을 강제로 바꾸지 않습니다. 설치 중단은 Installer의 중단 복구와 작업 로그를 사용합니다. 이전 버전 복원은 receipt/journal상 기록된 파일에 대해서만 가능합니다.

업데이트 확인 실패는 네트워크·인증·실제 stable릴리스 부재 때문일 수 있습니다. 이 경우 기존 설정/설치 사용은 유지됩니다. 버튼 잘림과 경로/찾기 정렬은 최신 소스에서 수정했고 최소 창/확대 배치를 검증했습니다. 실제 모니터 DPI와 수동 파일 대화상자, 게임/HMD동작까지 모든환경에서 수용한 것은 아닙니다.
