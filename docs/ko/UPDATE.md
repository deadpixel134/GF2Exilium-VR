# 업데이트 방법

[한국어](../ko/UPDATE.md) | [English](../en/UPDATE.md) | [日本語](../ja/UPDATE.md) | [简体中文](../zh-CN/UPDATE.md)

현재 정식 버전은 **1.0.0**입니다. 새 정식 버전이 나오면 릴리스 ZIP을 내려받아 인스톨러로 업데이트할 수 있습니다. 소스나 문서가 바뀌었다고 설치된 프로그램이 자동으로 바뀌지는 않습니다.

## 릴리스 ZIP으로 업데이트

1. [릴리스 페이지](https://github.com/deadpixel134/GF2Exilium-VR/releases)에서 원하는 정식 버전의 **GF2VR-Native-SelfContained-버전.zip**을 받습니다.
2. 게임을 종료하고 새 ZIP을 별도 폴더에 전부 풉니다.
3. 새 인스톨러에서 기존 게임 폴더와 새 패키지 폴더를 확인합니다.
4. 표시된 버전과 **업데이트** 안내를 확인하고 진행합니다.
5. 완료 후 **설정 열기**로 기존 설정을 확인하고 게임을 직접 실행합니다.

자세한 화면 안내는 [설치 방법](INSTALLATION.md)을 참고하세요. 사용자 설정은 보존하며, 이전 파일 위에 일부 파일만 섞어 복사하는 방식은 피하세요.

## 설정 프로그램에서 업데이트 확인

이 기능은 PC에 설치된 **GitHub CLI(gh)**와 로그인 상태를 사용합니다. CLI를 사용하지 않는 경우 위의 공개 ZIP 다운로드 방식으로 업데이트하세요. 토큰이나 비밀번호를 GF2VR 설정 파일에 적을 필요는 없습니다.

## 업데이트 알림이 보이면

1. 설정 프로그램을 열었을 때 새 버전 알림이 있는지 확인합니다.
2. 게임이 실행 중이라면 종료합니다.
3. 업데이트 버튼을 누르고 안내된 버전을 확인합니다.
4. 진행에 동의했다면 프로그램이 파일을 받으며 작업하도록 기다립니다.
5. 설정 프로그램이 닫혔다가 다시 열리면 결과를 확인합니다. 게임은 직접 다시 실행하세요.

업데이트 버튼은 사용할 수 있는 새 버전이 확인될 때 표시됩니다. 창이 다시 열리지 않거나 오류가 나타나면 기존 실행 경로로 설정 프로그램이나 인스톨러를 열어 상태를 확인하세요.

## 알림이 나오지 않는 경우

새 버전이 없거나, 현재 설치 방식이 자동 업데이트 대상이 아니거나, 저장소 접근·인터넷 연결을 확인할 수 없는 경우일 수 있습니다. 단순히 업데이트 버튼이 없다는 것만으로 설치가 고장 난 것은 아닙니다.

첫 정식 버전인 1.0.0에서는 아직 이후 버전이 없으므로 새 버전 알림이 없어도 정상입니다. 초안과 사전 릴리스는 정식 업데이트 대상으로 선택하지 않습니다.

업데이트 확인이나 파일 검사에 실패하면 기존 설치를 유지하도록 되어 있습니다. 문제가 반복되면 [문제 해결 안내](TROUBLESHOOTING.md)에 따라 메시지를 확인하세요.

## 중단되거나 이전 버전으로 돌아가려면

업데이트가 중단되었다면 [중단 복구](INSTALLATION.md)를 사용하고, 완료된 새 버전에서 문제가 생겼다면 인스톨러가 제공하는 직전 버전 복귀 안내를 확인합니다. 복구나 제거를 하기 전에도 게임을 종료하세요.
