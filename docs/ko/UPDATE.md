# 업데이트 방법

**현재 최신 전체 설치 파일과 실제 정식 릴리스를 이용한 업데이트는 제공·확인이 끝나지 않았습니다.** 아래는 사용할 수 있는 업데이트가 준비되었을 때의 사용 방법입니다. 소스나 문서가 바뀌었다고 설치된 프로그램이 자동으로 바뀌지는 않습니다.

## 업데이트 알림이 보이면

1. 설정 프로그램을 열었을 때 새 버전 알림이 있는지 확인합니다.
2. 게임이 실행 중이라면 종료합니다.
3. 업데이트 버튼을 누르고 안내된 버전을 확인합니다.
4. 진행에 동의했다면 프로그램이 파일을 받으며 작업하도록 기다립니다.
5. 설정 프로그램이 닫혔다가 다시 열리면 결과를 확인합니다. 게임은 직접 다시 실행하세요.

업데이트 버튼은 사용할 수 있는 새 버전이 확인될 때 표시됩니다. 창이 다시 열리지 않거나 오류가 나타나면 기존 실행 경로로 설정 프로그램이나 인스톨러를 열어 상태를 확인하세요.

## 알림이 나오지 않는 경우

새 버전이 없거나, 현재 설치 방식이 자동 업데이트 대상이 아니거나, 저장소 접근·인터넷 연결을 확인할 수 없는 경우일 수 있습니다. 단순히 업데이트 버튼이 없다는 것만으로 설치가 고장 난 것은 아닙니다.

현재 저장소는 비공개이며 처음에는 저장소 소유자 본인의 사용을 전제로 합니다. 다른 사용자의 다운로드·업데이트 이용 방법은 아직 정하지 않았습니다. 계정 비밀번호나 토큰을 설정 파일에 적어 해결하려고 하지 마세요.

## 파일을 직접 전달받았다면

게임을 종료하고 새 압축 파일을 별도 폴더에 전부 푼 뒤, 인스톨러에서 기존 게임 폴더와 새 패키지 폴더를 선택합니다. 화면의 버전과 업데이트 안내를 확인한 후 진행합니다. 자세한 순서는 [설치 안내](INSTALLATION.md)를 참고하세요.

이전 파일 위에 일부 파일만 섞어 복사하는 방식은 피하세요. 업데이트가 중단되었다면 [중단 복구](INSTALLATION.md)를 사용하고, 완료된 새 버전에서 문제가 생겼다면 인스톨러가 제공하는 이전 버전 복원을 확인합니다.

업데이트 확인이나 파일 검사에 실패하면 기존 설치를 유지하도록 되어 있습니다. 문제가 반복되면 [문제 해결 안내](TROUBLESHOOTING.md)에 따라 메시지를 확인하세요.
