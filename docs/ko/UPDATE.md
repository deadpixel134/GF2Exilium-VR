## 설정 프로그램에서 업데이트

정상적인 **1.1.6 이상 관리 설치**는 설정 프로그램 실행 시 공개 GitHub 릴리스를 확인합니다. 새 버전 알림에서 **업데이트**를 승인하면 다운로드·검증·설치합니다. 현재 업데이트 경로는 GitHub CLI 설치나 로그인이 필요하지 않습니다.

설치가 진행되기 전에 게임을 종료하고, 프로그램의 종료 안내를 따르세요. 업데이트 확인 실패만으로 기존 설치가 바뀌지는 않습니다.

## 알림이 없거나 업데이트가 실패할 때

1. [최신 릴리스](https://github.com/deadpixel134/GF2Exilium-VR/releases/latest)에서 현재 사용하는 Clean 또는 Dirty의 **전체 ZIP**을 받습니다.
2. ZIP 전체를 새 폴더에 풉니다. 기존 폴더에 파일을 섞지 마세요.
3. 게임과 기존 설정·인스톨러를 종료합니다.
4. 새 ZIP의 `GF2VR.Installer.exe`에서 기존 게임 위치와 종류를 확인해 설치합니다.

1.1.4 이하 또는 구버전의 업데이트 확인이 동작하지 않는 환경도 이 경로로 한 번 업데이트할 수 있습니다. 새 파일을 게시하는 것만으로 연결되지 않는 구버전 사용자에게 알림을 전달할 수는 없습니다.

## 보존되는 항목과 복구

같은 종류의 업데이트는 호환되는 사용자 설정과 설치 기록을 유지합니다. Clean↔Dirty 전환은 원하는 종류의 전체 ZIP과 인스톨러로 진행합니다. 파일 변조·소유권 불일치·실행 중인 게임 때문에 거부되면 검사를 우회하지 말고 [문제 해결](TROUBLESHOOTING.md)을 확인하세요. 중단 복구와 이전 설치 복원은 [설치 안내](INSTALLATION.md)를 따릅니다.
