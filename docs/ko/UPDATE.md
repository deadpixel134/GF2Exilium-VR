# 업데이트

설정 앱은 유효한 Installer설치 기록이 있는 경우 비동기로 기존 비공개 저장소의 승인된 stable릴리스를 조회합니다. 더 높은 버전과 정해진 자산/descriptor/hash가 일치하면 알리고, 사용자가 확인한 뒤 검증·staging·설정 앱 종료 확인·Installer교체·설정 앱 재실행을 진행합니다. draft/prerelease와 임의 ZIP은 제외합니다.

초기 대상은 저장소 소유자 본인입니다. 기존 로컬 GitHub CLI인증을 선택적으로 사용하며, 배포 앱에 공용 토큰을 포함하지 않습니다. 인증/네트워크/다운로드/검증 실패 시 설정 앱 사용과 기존 설치는 유지합니다. 게임 실행 중 교체는 거절하고 receipt/hash/복구 계약을 재검사합니다. 개발 설치를 제품 설치로 자동 인수하지 않습니다.

현재 실제 stable제품 업데이트 다운로드는 수용되지 않았습니다. 데스크톱 점검은 현재 보조 프로그램과 기존0.4/0.5검증 패키지의 offline업데이트/복구입니다. 소스 push 자체는 릴리스·자동 업데이트 배포가 아닙니다. 다른 사용자 private접근은 별도 결정이 필요합니다.
