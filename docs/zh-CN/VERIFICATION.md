# 已验证的行为与限制

[한국어](../ko/VERIFICATION.md) · [English](../en/VERIFICATION.md) · [日本語](../ja/VERIFICATION.md) · [简体中文](VERIFICATION.md)

本文说明正式版 1.0.1 的支持对象与验证范围。用户对当前实现的实机确认、发布文件的本地验证，以及在其他 PC 上的确认，分别记录。

## 支持对象

需要 Windows x64 PC 上合法安装的游戏及 VR 环境。**2.0.3936** 是实机验证的基准版本。原始游戏的 SHA-256、文件大小或缓存差异不会阻止安装，但这并不保证其他游戏版本的 VR 兼容性。

## 设置程序与安装程序

在独立测试文件夹中验证了以下行为。

- 设置保存与读取、默认值及配置文件导入和导出
- 无效设置值的错误提示，以及语言选择的保存
- 安装、更新、卸载、恢复上一版本及恢复中断操作
- 保留已有设置与其他文件的行为
- 进度、操作日志，以及安装程序查找匹配设置程序的行为
- 三种语言界面，以及小窗口、放大布局中的按钮对齐

上述程序界面语言为韩语、英语和日语，不包括中文。这些检查没有更改实际游戏文件或用户设置。

1.0.1 已通过 988 项托管检查、214 项原生边界检查，以及不启动游戏的宿主、导出、重建和 ZIP 预检。覆盖重命名、嵌套及 Unicode 路径、多目标拒绝、变更的原始游戏文件及损坏的产品文件。尚未记录修改后在报告者 PC 或真实游戏/HMD 中运行的结果。

## 当前实现的实机确认

下述实机观察属于 1.0.0 的基准实现。1.0.1 修改安装目标查找及路径处理，尚未记录修改后在报告者 PC 或游戏/HMD 中的验证。

此前已对支持场景的立体画面、辅助面板与 UI 操作、摇杆移动和转向、世界抓取、活动层 UI 显示设置，以及游戏操作模式下的 WASD、F、Escape 输入进行实机确认。包含世界大小联动、按下左摇杆恢复视点、按下右摇杆切换相机跟随，以及当前设置程序、安装程序界面的实现，以用户确认测试完成为依据，固定为正式版本。

针对活动层中报告的每隔 2～4 秒卡顿，修正了引发重复相机警告的调用。之后的游戏日志未再出现该警告，用户也选择将当前实现作为稳定版本。这不等于保证某个测量所得的最低帧率，或在所有情况下都毫无中断。

## 发布文件验证与限制

发布用原生模块保留上述实现的渲染与输入代码，并调整为以游戏安装文件夹为基准查找文件。已在本地检查路径迁移、Windows API 调用、导出项及文件完整性。尚未另行记录将这一个发布二进制文件重新在游戏/HMD 中运行的结果。

虽然随包提供所需的 .NET 运行时，但尚未在未安装 .NET 的全新 Windows PC 上，重新验证从安装到 HMD 运行的完整流程。也没有覆盖全部场景切换和按钮组合。

## 更新与分发

已使用**新的 1.0.1 安装程序**，在不启动游戏的文件夹中检查从 1.0.0 更新至 1.0.1、恢复上一版本及中断恢复。尚未验证旧 1.0.0 设置程序的自动替换流程及实际用户 PC 上的完成结果。

遇到问题时，请按照[故障排查指南](TROUBLESHOOTING.md)整理场景、操作、设备环境及错误信息。下载见[发布指南](RELEASE_READINESS.md)。
