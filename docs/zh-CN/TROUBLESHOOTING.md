# 遇到问题时

[한국어](../ko/TROUBLESHOOTING.md) · [English](../en/TROUBLESHOOTING.md) · [日本語](../ja/TROUBLESHOOTING.md) · [简体中文](TROUBLESHOOTING.md)

## 1.1.6 — 修复自动更新

设置GUI启动时检查公开GitHub发行版。批准通知中的 **更新** 后，将下载、校验并安装。从1.1.6开始，无需GitHub CLI或登录。

修复旧客户端使用固定白名单拒绝新构建的问题。客户端校验发行版与文件哈希、版本类型及当前文件归属，再由经过验证的新安装程序完成最终构建校验、备份和安装。保留Clean/Dirty类型与用户设置。

1.1.4及更早版本需要此次手动更新一次：将所选Clean/Dirty ZIP完整解压到新文件夹，并运行其中的新GF2VR.Installer.exe。更新检查正常的1.1.5环境可直接使用GUI更新。旧版所需GitHub CLI缺失的用户也需此次通过ZIP安装一次。安装1.1.6之后，GUI更新无需CLI或登录。

本版保留与1.1.5完全相同的VR DLL。保留日志默认关闭、明确开启设置及首次清理排除状态，以及面板和接触设置。安装前关闭游戏与设置窗口。界面语言仍为韩语、英语和日语。

## 1.1.5 — 日志记录设置

Clean和Dirty均在设置GUI中新增 **诊断 → 自动记录日志**。默认 **关闭**，旧设置中缺少此项时也保持关闭。保存后重启游戏生效。设置程序的界面语言仍为韩语、英语和日语。

首次更新安装时，仅为日志关闭的用户清理一次旧VR自动日志。**日志开启的用户保留已有日志，并排除在此次首次清理之外。** 之后改为关闭也不会延迟删除旧日志。保留设置、其他模组文件和手动收集的资料。

排查问题时再开启日志。开启后会继续追加到同一构建的日志文件，容量可能持续增加。

更新1.1.5时，请将所选Clean或Dirty ZIP完整解压到新文件夹，并使用随附的新GF2VR.Installer.exe安装。旧设置程序可能拒绝新的native配置。保留已有设置。

> **使用 VR 前必须在游戏设置中关闭抗锯齿。**

1.1.3 将 PR #1 的 3DMigoto 默认 wrapper 模式兼容性修改同时提供给 Clean 和 Dirty。保留游戏 wrapper，VR 复制与 OpenXR 使用实际 D3D11 设备/context。DLL 随附匹配的设置程序与安装程序元数据。

## 1.1.1 — Clean / Dirty

| 功能 | Clean | Dirty |
|---|---|---|
| 常规 VR、立体画面、控制器输入和设置 | 包含 | 包含 |
| 双手位置的白色球体 | 包含 | 包含 |
| 角色胸部接触与变形 | 不包含 | 包含 |

两个版本的常规 VR 源码、版本和更新保持一致。只有 Dirty 包含接触变形代码；Clean 在构建时排除该实现，而不是仅将其关闭。

安装、切换和移除均保留用户设置。可选 touch_interaction.json 仅由 Dirty 使用。移除时如有记录的上一安装则恢复，否则仅删除本工具拥有的文件。已修改或归属不明的 DLL 会被保留并拒绝覆盖。不要单独复制 version.dll，也不要混用不同安装包的文件。

已确认 Quest 3 和 Galaxy XR 所报告的左右画面错位由抗锯齿导致。使用 VR 前，请在游戏设置中关闭抗锯齿。

以下保留此前版本的详细说明。当前下载和验证范围以上方 1.1.1 说明为准。


请先确认问题发生在哪个操作阶段。设置保存、安装更新、实际 VR 画面与输入的问题，需要检查的内容各不相同。设置程序和安装程序界面目前支持韩语、英语和日语，不支持中文；本指南以中文说明各项功能。

## 提示找不到游戏文件夹

选择**包含 GF2_Exilium.exe 的文件夹**，或包含它的安装目录。安装程序会在不同名称及嵌套结构中查找可执行文件。若找到多个，请选择更靠近目标游戏的文件夹。 若所选目录过大而无法完成搜索，请选择更靠近可执行文件的文件夹。安装程序中只需选择游戏位置，解压后的安装文件会自动读取。

## 提示缺少软件包文件或无法安装

- 确认已经先将 ZIP 全部解压。
- 确认没有单独移动可执行文件。
- 确认没有将 GitHub 的源码下载 ZIP 当作安装包。
- 使用 [1.0.2 发布页](https://github.com/deadpixel134/GF2Exilium-VR/releases/tag/v1.0.2)中的安装 ZIP。原始游戏的 SHA-256、大小或缓存差异不会阻止安装，但产品软件包损坏或哈希不匹配仍会阻止安装。

如果文件缺失或损坏，请重新下载发布 ZIP 并全部解压到一个新文件夹。请勿随意修改被安装程序拒绝的文件来绕过检查。

## 提示文件已修改或没有所有权记录

这不是原始游戏版本或 SHA-256 错误。现有 `version.dll` 与安装记录不符，或因手动复制等原因没有所有权记录，因此文件被保留。1.0.2 中，即使没有记录，只要内容与当前软件包最终安装的文件完全一致，就会先备份再安装；卸载时恢复原有文件。其他 DLL 和已修改文件仍会受到保护。请保留安装记录和备份，并按原有模组的说明卸载。手动复制旧版本等与当前软件包内容不同的文件不会自动接管。

## 头显没有画面或周期性卡顿

检查 SteamVR/OpenXR 与头显的连接状态，完全退出游戏后再按平常方法启动。确认 PC 游戏画面是否也同时停顿，有助于缩小原因范围。

如果问题始于提高画质倍率后，请恢复到最后正常使用的数值。1.0.0 包含对活动层周期性卡顿相关重复相机警告调用的修正。如果仍然发生，请同时说明场景、重复间隔，以及 PC 画面与 HMD 中哪一端发生停顿。本项目不保证所有设备都能达到固定帧率。

## “打开设置”按钮被禁用

表示未找到与当前游戏安装匹配的设置程序。确认游戏文件夹是否正确，再点击**重新检查**。如果只单独复制了设置程序或安装程序，可能缺少随包提供的文件。

如果提示中给出了运行路径，请尝试从该路径打开。问题仍未解决时，请查看错误信息，不要混用不同程序和安装文件。

## 无法保存或安装

先确认游戏已完全退出。即使关闭了窗口，游戏也可能仍在运行。

如果提示数值错误，请检查输入框中是否包含单位或文字。小数点使用英文句点。如果数值过大或设备无法处理，请恢复到之前的数值或默认值。

如果提示文件访问错误，请确认显示的文件夹是否正确，并检查其他程序是否正在使用该文件。如果是为了保护已修改文件而停止操作，请先备份文件并确认发生了什么更改。

## 已保存，但游戏中没有变化

确认保存后已经退出并重新启动游戏。导入配置文件或点击默认值后，也需要点击**保存**。

按下右摇杆更改的相机跟随状态仅对本次游戏有效。如果希望更改下次启动的初始状态，需要在设置程序中保存。

## 辅助面板、点击或摇杆操作与预期不同

1. 确认控制器连接正常。
2. 在 PC 上选中游戏窗口。
3. 检查设置中是否更改了移动、转向手，或面板、指针手。
4. 如果正在按住辅助面板手的 Trigger，请尝试松开。按住期间会进入 WASD 游戏操作模式。
5. 分段转向需要让摇杆先回中，再次推动。

在 3D 画面中，用面板手的 Grip 打开或关闭辅助面板。此操作不会隐藏普通 2D 画面的正面面板。请参考[操作指南](USAGE.md)。

## 世界抓取无法移动

此功能默认关闭。确认已在设置中启用，分别选择至少一个激活按钮和一只要追踪的手，并且已经保存和重新启动游戏。

如果所选组合会优先触发其他面板或 UI 操作，请尝试默认的右手 Grip 与右手追踪。先松开当前按住的按钮，再重新按下。

## 无法检查更新

检查网络连接、GitHub CLI 的安装及登录状态，并确认是否确实存在新的正式版本。也可以从公开的[发布页](https://github.com/deadpixel134/GF2Exilium-VR/releases)直接下载 ZIP 更新。更新检查失败时会保留原有安装。请参考[更新指南](UPDATE.md)。

从 1.0.0 升级时，请直接下载 1.0.2 ZIP 并使用内附的新安装程序。若旧设置程序拒绝软件包，这一手动方式会保留设置及安装记录。

## 安装停止，或新版本出现问题

退出游戏后，重新打开安装程序并选择同一个文件夹。如果存在中断的操作，请使用**恢复中断操作**。如果更新已完成但出现问题，请查看恢复上一版本的提示。详见[卸载与恢复指南](INSTALLATION.md)。

## 反馈问题时

请说明点击了哪个按钮、在哪个步骤发生、错误信息，以及使用的头显和连接方式。安装问题可以参考操作日志最后显示的内容。

分享画面或文件前，请确认其中没有账号或认证信息。无须发送整套原始游戏文件。
