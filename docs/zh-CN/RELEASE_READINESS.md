# 下载与文件组成

[한국어](../ko/RELEASE_READINESS.md) | [English](../en/RELEASE_READINESS.md) | [日本語](../ja/RELEASE_READINESS.md) | [简体中文](../zh-CN/RELEASE_READINESS.md)

在[最新正式发行版](https://github.com/deadpixel134/GF2Exilium-VR/releases/latest)的 **Assets** 中下载安装包。实际版本号和文件名以该页面为准。

| 文件 | 用途 |
|---|---|
| `GF2VR-Native-SelfContained-Clean-<version>.zip` | Clean 完整安装包 |
| `GF2VR-Native-SelfContained-Dirty-<version>.zip` | Dirty 完整安装包 |
| `CHECKSUMS.sha256` | 用于核对下载文件的 SHA-256 |
| `GF2VR-Clean-update.json` / `GF2VR-Dirty-update.json` | 供自动更新器使用的元数据；手动安装请使用 ZIP。 |
| GitHub `Source code` | 开发用仓库副本，不是安装包。 |

完整 ZIP 包含 `GF2VR.Installer.exe`、设置工具及所选类型的 VR 文件，并自带所需 .NET 运行时，普通用户无需自行构建。

全部解压后使用附带的安装器。不要只复制 DLL 或关闭完整性检查。[安装](INSTALLATION.md) · [更新](UPDATE.md)
