## 1.1.1 — Clean / Dirty

| 功能 | Clean | Dirty |
|---|---|---|
| 常规 VR、立体画面、控制器输入和设置 | 包含 | 包含 |
| 双手位置的白色球体 | 包含 | 包含 |
| 角色胸部接触与变形 | 不包含 | 包含 |

两个版本的常规 VR 源码、版本和更新保持一致。只有 Dirty 包含接触变形代码；Clean 在构建时排除该实现，而不是仅将其关闭。

安装、切换和移除均保留用户设置。可选 touch_interaction.json 仅由 Dirty 使用。移除时如有记录的上一安装则恢复，否则仅删除本工具拥有的文件。已修改或归属不明的 DLL 会被保留并拒绝覆盖。不要单独复制 version.dll，也不要混用不同安装包的文件。

已确认 Quest 3 和 Galaxy XR 所报告的左右画面错位由抗锯齿导致。使用 VR 前，请在游戏设置中关闭抗锯齿。

以下保留此前版本的详细说明。当前下载和验证范围以上方 1.1.1 说明为准。


通过安装程序的**打开设置**启动设置程序。也可以直接运行游戏安装文件夹中的 `vrmod/bin/GF2VR.Configurator/GF2VR.Configurator.exe`。请将可执行文件及随同安装的文件保留在同一个文件夹。可通过底部的 **한국어 / English / 日本語** 按钮切换界面语言，程序会记住所选语言。程序界面目前不支持中文，下文用中文说明各项功能。

## 应用更改后的设置

1. 退出游戏。
2. 调整所需项目，同时阅读项目下方的说明。
3. 点击**保存**并确认完成提示。
4. 自行重新启动游戏。

仅在设置窗口更改数字，不会立即应用到正在运行的游戏。输入数字时不要附加单位，小数点请使用英文句点，例如 0.5。

## 画质与立体感

**VR 渲染分辨率倍率**决定绘制 VR 画面的分辨率。提高数值可能让画面更清晰，但也会增加性能和显存负担；降低后画面可能变模糊。它不会改变 PC 画面或辅助面板的分辨率。

默认值是 1.0。如果出现问题，请恢复到此前正常使用的数值。并非所有设备都适合同一数值。视觉效果使用游戏默认设置，不提供逐项启用或关闭效果的选项。

## 移动与转向

| 设置 | 说明 |
|---|---|
| 启用摇杆移动 | 决定是否通过控制器摇杆移动 VR 视点。 |
| 移动使用哪只手 | 默认为左手。更改后，移动与转向摇杆的角色会同时互换。 |
| 启用摇杆转向 | 决定是否使用另一只手的摇杆转动视角。 |
| 转向方式 | 分段转向每次转动固定角度；平滑转向则在推动摇杆期间持续转动。 |
| 移动速度 | 摇杆移动的基础速度。默认值是 1.0。 |
| 移动速度手动倍率 | 调整基础移动速度的快慢。1.0 为原速，2 为两倍，0.5 为一半。 |
| 分段转向角度 | 分段模式每次转动的角度。默认值为 30°。 |
| 平滑转向速度 | 持续转向的速度。在分段模式下不使用此项。 |
| 摇杆死区 | 忽略摇杆轻微晃动的范围。松手后仍会移动时，请检查此项。 |
| 启动时跟随相机演出 | 决定游戏启动时是否跟随原始相机运动。默认开启。 |

更改移动手，与在**按钮**选项卡中交换面板、指针手，是不同的设置。

游戏运行中通过**按下右摇杆**改变相机跟随状态，不会更改已保存的初始设置。如果希望下次启动游戏时也采用同一状态，请在此窗口中保存。

## 世界抓取

世界抓取是一项按住按钮并移动手部来调整 VR 视点的功能。默认关闭，使用前需要先启用。

- **启用世界抓取**：开启或关闭此功能。
- **激活按钮**：选择左手或右手的 Grip 或 Trigger。
- **追踪哪只手**：选择以哪只手的运动为基准。

至少需要分别选择一个激活按钮和一只要追踪的手。默认选择是右手 Grip 与右手追踪。

负责辅助面板的手，其 Grip 优先用于开关面板；同一只手的 Trigger 用于游戏操作模式；指针手的 Trigger 则优先处理 UI 操作。初次使用时，建议先通过默认的右手 Grip 组合熟悉操作。

## 活动层 UI

关闭**显示主画面活动层 UI**后，会隐藏叠加在 VR 主画面上的活动层 UI。3D 画面与显示原始游戏画面的辅助面板仍然保留。

即使该选项开启，打开辅助面板时，主画面 UI 也会暂时隐藏，关闭辅助面板后重新显示。

## 按钮

| 设置 | 关闭：默认 | 开启 |
|---|---|---|
| 交换点击与返回按钮 | 指针手的 A 或 X 为点击，B 或 Y 为返回 | 互换这两个动作。 |
| 交换面板与指针手 | 左手负责辅助面板，右手负责指针 | 右手负责辅助面板，左手负责指针 |

更改面板手后，用于开关面板的 Grip 与用于游戏操作模式的 Trigger，也会转移到相应手上。此设置不会改变摇杆移动、转向的左右手分配。

游戏操作模式的 **X/A → F、Y/B → Escape** 输入，与普通点击、返回按钮互换相互独立。

## 世界大小

**世界大小倍率**调整周围世界给人的大小感。**1 代表 100%，2 代表 200%，0.5 代表 50%**。如需设置为 200%，请输入数字 2。

| 设置 | 说明 |
|---|---|
| 世界大小倍率 | 调整世界大小。建议先从默认值 1 开始，小幅调整。 |
| 将 Stereo Depth 与世界大小联动 | 根据世界大小自动调整游戏内双眼之间的距离。默认开启。 |
| Stereo Depth / 眼间距倍率 | 手动调整决定立体感的游戏内双眼间距。自动联动开启时，只显示当前值，不能直接编辑。 |
| 将移动速度与世界大小联动 | 世界变大时相应加快移动，变小时相应减慢。默认开启。 |

关闭眼间距自动联动后，可以当时的计算值为起点进行手动调整。重新开启后，会按照当前世界大小自动计算。此设置不能代替头显本身的瞳距调整。

即使关闭移动速度联动，**移动与转向**选项卡中的基础速度和手动倍率仍会保留，只去掉随世界大小自动调整的部分。

画面底部的**头部移动**显示的是按世界大小修正后的头部运动数值，不是摇杆移动速度，也不是可单独输入的项目。

## 保存与配置文件按钮

| 按钮 | 使用方法 |
|---|---|
| 保存 | 保存当前编辑的设置。应用时需要重新启动游戏。 |
| 重新读取 | 重新载入最后保存的设置。未保存的更改会丢失。 |
| 默认值 | 将设置项目恢复为默认值。随后需要保存才能应用。 |
| 导出 | 将当前设置另存为配置文件，可用于备份或在多组设置之间切换。 |
| 导入 | 载入已保存的配置文件。确认内容后，需要保存才能写入游戏设置。 |

数值旁的建议范围是调整时的起点参考，并不一律禁止超出建议范围的输入；但设备或功能无法处理的数值可能无法应用。发生错误时，请阅读提示并恢复到之前的数值或默认值。
