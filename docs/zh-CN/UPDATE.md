## 通过设置程序更新

正常的 **1.1.6 及以上受管理安装**会在设置程序启动时检查公开 GitHub 发行版。在通知中批准**更新**后，程序会下载、验证并安装。当前更新路径不需要 GitHub CLI 或登录。

安装前关闭游戏，并按程序提示退出相关窗口。仅更新检查失败不会更改现有安装。

## 没有通知或更新失败时

1. 从[最新发行版](https://github.com/deadpixel134/GF2Exilium-VR/releases/latest)下载当前 Clean 或 Dirty 类型的**完整 ZIP**。
2. 全部解压到新文件夹，不要混用安装包文件。
3. 关闭游戏及已有的设置程序、安装器。
4. 运行新 ZIP 中的 `GF2VR.Installer.exe`，确认原游戏位置和类型后安装。

1.1.4 及以下或旧更新器无法检查的环境，也可用此路径进行一次更新。仅发布新文件，无法通知那些不能连接发行源的旧客户端。

## 设置保留与恢复

同类型更新保留兼容的用户设置和安装记录。切换 Clean↔Dirty 时，使用目标类型的完整 ZIP 与安装器。若完整性、文件归属或游戏运行状态检查拒绝操作，请查看[故障排除](TROUBLESHOOTING.md)，不要绕过检查。中断恢复和恢复上一次安装见[安装指南](INSTALLATION.md)。
