# 更新方法

[한국어](../ko/UPDATE.md) · [English](../en/UPDATE.md) · [日本語](../ja/UPDATE.md) · [简体中文](UPDATE.md)

当前正式版本为 **1.0.0**。新正式版发布后，可以下载发布 ZIP 并通过安装程序更新。源码或文档发生变化，不会自动更改已经安装的程序。设置程序与安装程序界面目前仅支持韩语、英语和日语，不支持中文。

## 通过发布 ZIP 更新

1. 从[发布页](https://github.com/deadpixel134/GF2Exilium-VR/releases)下载所需正式版本的 **GF2VR-Native-SelfContained-版本.zip**。
2. 退出游戏，将新 ZIP 的全部内容解压到另一个文件夹。
3. 在新安装程序中确认原有游戏文件夹与新软件包文件夹。
4. 检查显示的版本和**更新**提示后继续。
5. 完成后，通过**打开设置**确认已有设置，并自行启动游戏。

详细界面说明见[安装方法](INSTALLATION.md)。更新会保留用户设置，请避免只将部分文件混合复制到旧文件上。

## 在设置程序中检查更新

此功能使用 PC 上安装的 **GitHub CLI（gh）**及其登录状态。不使用 CLI 时，请通过上述公开 ZIP 下载方式更新。无须将令牌或密码写入 GF2VR 设置文件。

## 出现更新提示时

1. 打开设置程序时，查看是否出现新版本提示。
2. 如果游戏正在运行，请先退出游戏。
3. 点击更新按钮，确认提示中的版本。
4. 同意继续后，等待程序下载文件并执行操作。
5. 设置程序关闭并重新打开后，检查结果。游戏需要自行重新启动。

只有确认存在可用新版本时，才会显示更新按钮。如果窗口没有重新打开或出现错误，请从原来的运行位置打开设置程序或安装程序，检查状态。

## 没有出现更新提示时

可能是尚无新版本、当前安装方式不支持自动更新，或无法确认仓库访问与网络连接。仅仅没有更新按钮，并不表示安装已损坏。

1.0.0 是首个正式版本，目前还没有后续版本，因此没有更新提示也属正常。草稿和预发布版本不会被选为正式更新目标。

更新检查或文件验证失败时，程序会保留原有安装。如果问题反复出现，请按照[故障排查指南](TROUBLESHOOTING.md)查看相关提示。

## 更新中断或需要返回上一版本时

更新中断时，请使用[恢复中断操作](INSTALLATION.md)；如果新版本已更新完成但出现问题，请查看安装程序提供的返回上一版本提示。恢复或卸载之前，也需要先退出游戏。
